# 坦克大戰恐龍

非對稱連線對戰原型。**多台坦克 vs 一隻大恐龍**，Godot 4.7 + 3D，區網直連。

灰盒原型，模型全部是內建幾何體。恐龍是 18 根骨頭的 Skeleton3D，每根掛一個方塊。

## 玩法

| | 坦克 | 恐龍 |
|---|---|---|
| 血量 | 140 | 1000 |
| 攻擊 | 砲彈（遠程，會受重力下墜） | 咬（只打前方，被建築擋住就咬不到） |
| 機動 | 慢，車身和砲塔分開轉，底盤有箭頭指車頭 | 快，可衝刺、跳躍、爬建築 |
| 資源 | 1.5 秒裝填一次 | 體力條（衝刺、跳躍、爬牆都會吃，歸零力竭） |

恐龍血歸零 → 坦克贏；坦克全滅 → 恐龍贏。

數值是照 **3 台坦克**抓的：恐龍咬四口殺一台（3.3 秒貼身），3 台坦克貼臉打滿
12.5 秒能殺恐龍。

場地 320×320，四周有 40 公尺高的圍牆，內部密集散布約 88 棟建築，高度 6~28 公尺。**建築會擋住恐龍的視線**——
中間隔著牆就咬不到，所以坦克可以繞柱子拉開距離。

恐龍的解法是**爬上去**：貼著牆按 W 往上爬，每秒吃 25 體力。滿體力剛好爬得完
最高的那棟（24 公尺）。但爬上屋頂就等於站在空曠處挨砲，是個取捨。

**場地圍牆不給爬**（一般建築照爬），所以恐龍能到的最高點就是「站上最高的屋頂再跳一下」
= 28 + 6.5 = 34.5 公尺，圍牆 40 公尺翻不出去。這條不變式寫進測試了。

體力歸零會**力竭**，要回到 30 才能再衝刺或攀爬——不然體力會在 0 附近抽動。
站著不動回體力的速度是移動中的兩倍多。

數值目前寫死，不隨人數變。

## 操作

```
WASD    移動
滑鼠     瞄準（坦克左右轉砲塔、上下抬砲管，俯 8° ~ 仰 20°）
左鍵     攻擊
Space   恐龍：跳躍
貼牆 W  恐龍：往上爬建築
Shift   恐龍：衝刺
Esc     開選單（繼續遊戲／回到大廳／離開遊戲）
```

準心畫在**砲彈 55 公尺處的實際落點**，不是螢幕正中央——遠距離要抬砲口。

## 連線

Godot 內建 ENet，**同區網直連**，連接埠 24680。開房的人當恐龍，加入的人當坦克。

跨網路（NAT 打洞）還沒做。

啟動參數，方便一台機器開兩個視窗：

```sh
TankWar.exe -- --host
TankWar.exe -- --join 127.0.0.1
TankWar.exe -- --offline    # 單機：我當坦克，打會跑的恐龍靶
```

## 離線練習模式

大廳有兩顆離線按鈕，不用連線就能玩：

| 模式 | 你是 | 靶 | 練什麼 |
|---|---|---|---|
| 我當坦克 | 一台坦克 | 一隻會繞圈跑的恐龍 | 提前量、抬砲口、彈道下墜 |
| 我當恐龍 | 恐龍 | 三台會繞圈跑的坦克 | 追擊、跳躍、爬牆、體力分配 |

靶不會還擊。撞到建築會自己滑開，所以路線不會太規律。打完會判勝負，
按 Esc 回大廳可以重開。

## 開發

```sh
godot                                    # 開專案
godot --headless --script test_battle.gd # 自我檢查（壞掉會 exit 1）
./build.sh                               # 打包 Windows + macOS 到 build/
```

打包需要先在 Godot 裡裝對應版本的 export templates。

| 檔案 | 做什麼 |
|---|---|
| `main.gd/tscn` | 大廳、連線、場地、勝負、HUD、準心 |
| `fighter.gd` | 坦克恐龍共用：血量、死亡、連線權限、中彈閃紅 |
| `tank.*` `dino.*` `shell.*` | 三個角色 |
| `trex.gd` | 暴龍的灰盒骨架模型（Skeleton3D + 方塊 + 程式動畫，見 [程序化動畫筆記](docs/程序化動畫.md)） |
| `fx.gd` | 一次性視覺效果（放大淡出後自刪） |
| `test_battle.gd` | 自我檢查 |

## 為什麼物理跑 120Hz

畫面通常跑 120fps 以上，物理留在預設的 60Hz 會讓每個位置被連續畫兩次，
動起來像有殘影（實測 53% 的畫面位置跟前一張完全一樣）。拉到 120 對齊後降到 0%。

如果在別的更新率螢幕上還是覺得頓，正解是開 `physics/common/physics_interpolation`，
但那要處理傳送點重置和 `_process` 裡動的節點，比較麻煩。

## 已知限制

- 不防作弊：移動由各自的客戶端算，主機只算傷害
- 沒有重生、回合、音效、骨架動畫
- 打包檔沒簽章，Windows 會跳 SmartScreen、macOS 要右鍵開啟
