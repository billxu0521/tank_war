# 西部牛仔打恐龍

非對稱連線對戰原型。**多個第一人稱牛仔 vs 一隻大恐龍**，Godot 4.7 + 3D，區網直連。

牛仔的手感參考 Hunt: Showdown，整套從 `~/project/FNE_project` 搬來（移動、蹲、傾身、
翻越、體力、三把槍）。恐龍是 18 根骨頭的 Skeleton3D，每根掛一塊 Blender 建的部件。
設計決定見 [docs/plans/2026-09-25-cowboy-vs-dino-design.md](docs/plans/2026-09-25-cowboy-vs-dino-design.md)。

**流程玩法還沒定案**。下面的蛋、撤離、計時是坦克版留下來的，先沿用。

## 玩法

| | 牛仔 | 恐龍 |
|---|---|---|
| 血量 | 150 | 1500 |
| 攻擊 | 手槍 25／霰彈 8×8／雙管 10×8（子彈是直線，打頭不加成） | 咬 100（F，只打前方、會被建築擋）＋ 火球 50（左鍵，吃體力） |
| 機動 | 走 5、跑 8.5 m/s（跑步吃體力），可蹲、探頭、翻過 1.5 公尺以下的東西 | 9 m/s，可衝刺、跳躍、爬建築 |

數值是**佔位版**：恐龍兩口咬死一個牛仔、3 個牛仔用手槍約 13.5 秒打死恐龍。
玩法定了再調。

**一局四分鐘。牛仔互為對手，先把蛋帶進撤離區的那個人贏。**時間到沒人撤離，恐龍贏。

無限重生，死了五秒後滿血回場。死亡的代價是**節奏**：身上的蛋會掉在原地被別人撿走。
打死恐龍**不是**勝利條件，只是讓牠消失五秒——不然理性玩法會變成牛仔先聯手弄死恐龍，
跟互相競爭矛盾。恐龍也**不能撿蛋**。

場地 320×320，四周 40 公尺高的圍牆，內部散布約 88 棟 6~28 公尺高的建築。
**建築會擋住恐龍的視線**，隔著牆咬不到。恐龍的解法是**爬上去**（貼牆按 W，吃體力），
但場地圍牆不給爬，翻不出去（這條不變式寫進測試了）。

## 操作

```
牛仔（鍵鼠和手把都能玩）
WASD 移動   滑鼠 看   左鍵 開槍   右鍵 舉槍（準、慢）   R 換彈
1/2/3 或滾輪 換槍   Shift 跑   Ctrl 蹲   Q/E 探頭
Space 跳；頂著矮牆按 Space＝翻越

恐龍
WASD 移動   滑鼠 轉身抬頭   左鍵 吐火球   F 咬   Space 跳   Shift 衝刺   貼牆按 W 爬

Esc 開選單（繼續遊戲／回到大廳／離開遊戲）
```

## 連線

Godot 內建 ENet，**同區網直連**，連接埠 24680。開房的人當恐龍，加入的人當牛仔。

- 開槍打中是**開槍的人自己判定**，再請主機扣血（`Cowboy.deal_damage`）。不防作弊。
- 跨網路（NAT 打洞）還沒做。

啟動參數，方便一台機器開兩個視窗：

```sh
TankWar.exe -- --host
TankWar.exe -- --join 127.0.0.1
TankWar.exe -- --offline    # 單機：我當牛仔，恐龍 bot 會追過來
```

大廳另有「離線測試：我當恐龍」，對手是三個會搶蛋、會開槍的牛仔 bot。

## 開發

```sh
godot                                    # 開專案
godot --headless --script test_battle.gd # 自我檢查（壞掉會 exit 1）
godot --headless --script sim.gd -- 20   # 全 bot 自動對戰 20 場，印勝率和局長
./build.sh                               # 打包 Windows + macOS 到 build/
godot --headless --quit --editor         # 新增 class_name 後重建型別快取
```

| 檔案 | 做什麼 |
|---|---|
| `main.gd/tscn` | 大廳、連線、場地、蛋與撤離、勝負、HUD |
| `fighter.gd` | 牛仔恐龍共用：血量、死亡、連線權限、中彈閃紅 |
| `cowboy/` | 牛仔：`cowboy.gd` 移動與 bot、`viewmodel.gd` 開槍、`weapon.gd` 槍的數值、`weapons/*.tscn` 三把槍 |
| `dino.*` `trex.gd` `fireball.*` | 恐龍、骨架程式動畫（見 [程序化動畫筆記](docs/程序化動畫.md)）、火球 |
| `assets/` | 從 FNE 搬來的槍模、音效、材質。授權見 `CREDITS.md` |
| `test_battle.gd` | 自我檢查 |
| `sim.gd` | 全 bot 自動對戰，把平衡問題變成可量測的 |

坦克版的程式在 git 歷史裡（`d59b432` 之前），`models/tank.glb` 還留給模型檢視器用。

設計討論整理在 [docs/設計討論.md](docs/設計討論.md)，來源是 Discord 論壇 `#夢想之地`。

## 為什麼物理跑 120Hz

畫面通常跑 120fps 以上，物理留在預設的 60Hz 會讓每個位置被連續畫兩次，
動起來像有殘影。拉到 120 對齊後就沒了。

## 平衡現況（10 場全 bot 對戰，佔位數值）

| | |
|---|---|
| 牛仔勝率 | **100%**（10 場都撤離成功） |
| 平均局長 | 82 秒（上限 240） |
| 平均死亡 | 牛仔 5.2 次／場，恐龍 0.6 次／場 |
| 牛仔死因 | 恐龍 61%，彼此互殺 38% |
| 持蛋被殺 | 佔撿蛋的 76% |

牛仔一面倒。蛋很常易手，但最後總有人跑進撤離區——恐龍一次只能追一個人。
這是 bot 的數字（沒有尋路、不翻越），當起點不是結論；勝負條件定了再調。

## 已知限制

- 不防作弊：移動由各自的客戶端算，開槍命中由開槍的人判定
- 別人的腳步聲聽不到；bot 的槍聲不分遠近
- bot 沒有尋路，卡牆就沿牆繞一段
- 打包檔沒簽章，Windows 會跳 SmartScreen、macOS 要右鍵開啟
