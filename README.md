# 西部牛仔打恐龍

非對稱連線對戰原型。**多個第一人稱牛仔 vs 一隻大恐龍**，Godot 4.7 + 3D，區網直連。

牛仔的操作照 Hunt: Showdown，移動系統從 `~/project/FNE_project` 搬來（移動、蹲、
翻越、體力）。牛仔、三把槍、恐龍和場景物件（穀倉、農舍、筒倉、柵欄、乾草捲、樹、山崖、麥田、篷車）的模型都是用 Blender 程式建的（`blender/`）。
場景是黃昏的鄉村：穀倉、農舍、筒倉、果園、麥田、牧場柵欄。
設計決定見 [docs/plans/2026-09-25-cowboy-vs-dino-design.md](docs/plans/2026-09-25-cowboy-vs-dino-design.md)。

**流程玩法還沒定案**。下面的蛋、撤離、計時是坦克版留下來的，先沿用。

## 玩法

| | 牛仔 | 恐龍 |
|---|---|---|
| 血量 | 150 | 1500 |
| 攻擊 | 見下方三把槍；**有效射程內打頭一槍死** | 咬 100（F，只打前方、會被建築擋）＋ 火球 50（左鍵，吃體力） |
| 機動 | 走 5、跑 8.5 m/s（全力跑約 18 秒），可蹲、翻過 1.5 公尺以下的東西（跟 Hunt 一樣沒有探頭和趴下） | 9 m/s，可衝刺、跳躍、爬建築 |

數值是**佔位版**：恐龍兩口咬死一個牛仔、3 個牛仔用左輪約 10 秒打死恐龍。
玩法定了再調。

### 三把槍

| 鍵 | 槍 | 彈匣／備彈 | 傷害 | 有效射程 | 特色 |
|---|---|---|---|---|---|
| 1 | 左輪 | 6／18 | 50（三發死） | 25 m | 每發扳一次擊錘（0.45 秒）；**腰射按住左鍵＝搧擊錘**，0.16 秒一發但很散 |
| 2 | 單管散彈 | 1／10 | 10 顆 × 14 | 8 m | 折開式，一發就要換（1.6 秒）；30 公尺外就散光 |
| 3 | 槓桿步槍 | 10／20 | 60 | 60 m | 每發拉一次桿（0.8 秒），射程 250 公尺；遠距離要閉氣 |

子彈有限，Hunt 的節奏就是省著打。
超過有效射程，打頭不再秒殺、傷害線性遞減，到射程盡頭剩一半。
**子彈會飛、會掉**：初速左輪 330、散彈 300、步槍 440 m/s，重力 9.8。從鏡頭中心出發，
近距離打哪中哪，步槍打 150 公尺約掉 57 公分，遠距離要抬高一點。

### Hunt 式的操作規則

- **兩條體力**：跑步體力（跑、跳、翻越、閉氣；全力跑約 18 秒）和近戰體力（左下血條下的黃條，只有槍托用）。
  任何一條在出力，兩條都不回；停 2 秒後才開始回
- **沒有準心**：跟 Hunt 一樣靠槍身瞄，腰射散布 4 度、連開撐大到 8 度。打中人時畫面中間閃一下紅色 +（命中提示）
- **舉槍會晃**，舉槍時按住 Shift **閉氣**就停住，但吃體力；體力不夠時手更抖；**蹲下晃一半**
- **舉槍時 Shift 是閉氣不是跑步**；跑起來會自動站起來、放下槍
- **V 槍托近戰**：點一下輕擊（25 傷、15 體力），按住蓄力 0.6 秒再放開是重擊（60 傷、30 體力）。
  沒有格擋，跟 Hunt 一樣只能拉開距離或開槍。F 留給以後的互動
- **C 切換蹲下**，Ctrl 是按住蹲
- 逐發裝填（左輪、步槍）換到一半可以直接開槍中斷
- **F 互動**：看著門按 F 開關（穀倉正面是兩扇往外拉的滑門、後面一扇小門，農舍是推門），
  看著梯子按 F 抓住、W/S 上下、爬到頂自動站上去、Space 或 F 放手。
  穀倉的梯子通閣樓；**筒倉外面的梯子爬得到 17 公尺以上的頂端**（全場最高的狙擊點，摔下來必死）
- **建築是空心的**：穀倉有閣樓、馬廄隔間、乾草、工作台；農舍分客廳和臥室。
  **窗戶是開口**，可以從窗戶開槍，也可以翻進翻出（農舍窗台 1 公尺）。恐龍太大進不去
- **翻越**：靠近柵欄、窗台、乾草捲、矮牆（0.4～1.5 公尺），按住往前＋Space 就翻（不用先撞上去）。
  身體撐上去、越過、落下，鏡頭會點頭側傾、槍放低
- **左輪照 Hunt 的 Pax 做動作**：腰射往內斜、開槍槍口大翻冒黑火藥煙、拇指勾擊錘扳回來；
  換彈把槍舉起來開裝填門，左手推退殼桿頂出空殼、捏子彈一顆一顆塞，轉輪跟著轉（參考影片 `docs/movie/pax.mov` 太大沒進 git）
- **長槍換彈有手部動作**（參考 `docs/movie/` 的影片）：散彈折開、空殼掉出來，右手從右下拿黃色霰彈塞進膛室；
  步槍往左翻露出右側，右手一顆一顆從側面的裝填門壓進去。換到一半開槍，手會滑回握把
- **手腳**：第一人稱看得到握槍的手（長槍兩手，步槍右手跟著拉桿動、散彈左手跟著槍管折開）；
  低頭看得到自己的靴子，地上有自己的影子；別人走路時兩條腿會前後擺
- **摔落傷害**：4 公尺以下沒事、15 公尺摔死，中間照比例；落在乾草捲上減半

### 沙盒模式

大廳按「沙盒模式」或用 `-- --sandbox` 啟動。一個人在靶場練槍：
前方 10／25／50／100 公尺各站一個牛仔靶，旁邊 45 公尺一隻不會動的恐龍。
沒有時間限制、子彈無限，靶打死會在原地重生。出生點旁有柵欄和乾草捲可以練翻越。

**大廳只有兩個模式：連線模式（大家都是牛仔）和沙盒模式。** 恐龍暫時不上場（程式都還在，
沙盒裡有恐龍靶），玩法定了再接回來。

**連線模式一局四分鐘。牛仔互為對手，先把蛋帶進撤離區的那個人贏。**時間到沒人撤離就沒人贏。

### 遊戲局控制（Esc 選單，只有主機和沙盒）

- **＋移動標靶**：在你前方 25 公尺，左右 6 公尺來回走，不會還擊；撞到東西會回頭
- **＋牛仔 bot**：會開槍的電腦牛仔。連線模式會搶蛋，沙盒裡直接來找你打
- **清除所有 bot**

電腦用負數編號（-1、-2…），由主機操控、位置同步給所有人；玩家的連線編號一定是正數。

無限重生，死了五秒後滿血回場。死亡的代價是**節奏**：身上的蛋會掉在原地被別人撿走。
打死恐龍**不是**勝利條件，只是讓牠消失五秒——不然理性玩法會變成牛仔先聯手弄死恐龍，
跟互相競爭矛盾。恐龍也**不能撿蛋**。

場地 320×320，**有高低起伏的丘陵**（正負 10 公尺、山頂到谷底差 20 公尺，最陡不超過 40 度，人和恐龍都走得上去），
農莊、撤離區、沙盒靶場的地是整平的。地圖分成 5×5 塊鄉村農地，每塊隨機是**農莊**（穀倉＋農舍＋筒倉＋柵欄）、
**果園**、**麥田**（80 公分高的麥子，蹲著會被擋住一部分；乾草捲）或**牧場**（柵欄欄位）。柵欄 1 公尺、乾草捲 1.4 公尺，
牛仔都翻得過去。**建築會擋住恐龍的視線**，隔著牆咬不到；樹冠擋視線不擋子彈。
**灌木叢**（全場約 260 叢，兩三叢一群）只擋視線、不擋子彈、走得進去：灌木 1.5 公尺高，站著頭會露出來，**蹲進去就藏住**，6 公尺外的 bot 看不到你。
恐龍的解法是**爬上去**（貼牆按 W，吃體力），穀倉屋頂和筒倉是制高點。
四周 40 公尺高的山崖不給爬，翻不出去（這條不變式寫進測試了）。

## 操作

```
牛仔（鍵鼠和手把都能玩）
WASD 移動   滑鼠 看   左鍵 開槍（左輪腰射按住＝搧擊錘）   右鍵 舉槍   R 換彈
1 左輪  2 單管散彈  3 槓桿步槍（或滾輪）   V 槍托（按住＝重擊）   F 開門／爬梯子
Shift 跑（舉槍時＝閉氣）   C 切換蹲下 / Ctrl 按住蹲
Space 跳；頂著矮牆、柵欄按 Space＝翻越

恐龍
WASD 移動   滑鼠 轉身抬頭   左鍵 吐火球   F 咬   Space 跳   Shift 衝刺   貼牆按 W 爬

Esc 開選單（繼續遊戲／回到大廳／離開遊戲）
```

## 連線

Godot 內建 ENet，**同區網直連**，連接埠 24680。大家都是牛仔。

- 開槍打中是**開槍的人自己判定**，再請主機扣血（`Cowboy.deal_damage`）。不防作弊。
- 跨網路（NAT 打洞）還沒做。

啟動參數，方便一台機器開兩個視窗：

```sh
TankWar.exe -- --host
TankWar.exe -- --join 127.0.0.1
TankWar.exe -- --sandbox    # 沙盒：靶場練槍
```


## 開發

```sh
godot                                    # 開專案
godot --headless --script test_battle.gd # 自我檢查（壞掉會 exit 1）
./build.sh                               # 打包 Windows + macOS 到 build/
godot --headless --quit --editor         # 新增 class_name 後重建型別快取
```

| 檔案 | 做什麼 |
|---|---|
| `main.gd/tscn` | 大廳、連線、場地、蛋與撤離、勝負、HUD |
| `terrain.gd` | 丘陵地形：高度、整平區、畫面網格和碰撞（同一份高度） |
| `interact/` | F 互動的東西：`door.gd`（開關走主機、晚加入補送）、`ladder.gd`（爬的邏輯在 cowboy.gd） |
| `fighter.gd` | 牛仔恐龍共用：血量、死亡、連線權限、中彈閃紅 |
| `cowboy/` | 牛仔：`cowboy.gd` 移動與 bot、`viewmodel.gd` 開槍與 Hunt 規則、`weapon.gd` 槍的數值與程式動作、`weapons/*.tscn` 三把槍 |
| `models/*.glb` `blender/*.py` | 模型和產生它的 Blender 腳本（牛仔、槍、恐龍、場景物件），重建方式見 `blender/README.md` |
| `dino.*` `trex.gd` `fireball.*` | 恐龍、骨架程式動畫（見 [程序化動畫筆記](docs/程序化動畫.md)）、火球 |
| `assets/` | 從 FNE 搬來的音效、材質。授權見 `CREDITS.md` |
| `test_battle.gd` | 自我檢查 |

坦克版的程式和模型在 git 歷史裡（`d59b432` 之前）。大廳的「檢視模型」可以單獨看牛仔、三把槍和暴龍。

## 為什麼物理跑 120Hz

畫面通常跑 120fps 以上，物理留在預設的 60Hz 會讓每個位置被連續畫兩次，
動起來像有殘影。拉到 120 對齊後就沒了。


## 已知限制

- 不防作弊：移動由各自的客戶端算，開槍命中由開槍的人判定（子彈在開槍的人那邊飛，別人畫面上是同一條彈道的外觀）
- 別人的腳步聲聽不到；bot 的槍聲不分遠近
- 步槍借手槍聲壓低音高，沒有專屬音效；手和腿是一整塊，手指不會動、走路只有腿擺
- bot 沒有尋路，卡牆就沿牆繞一段
- 打包檔沒簽章，Windows 會跳 SmartScreen、macOS 要右鍵開啟
