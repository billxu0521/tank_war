# ranch 地面待審新版

主線遊戲的既存 ranch 自動套用，未修改原場景、地形、碰撞、麥株、掩體或出生點。`--original-ground` 啟動參數回到原地面；靶場及伺服器排除。正式合併前仍為 Draft PR 候選。

全圖用途地材以已核可30%為基準：小鎮通行與門前、麥田耕作與入口、農莊院落、林下與路肩分布各有理由。精細層只套已驗證的林屋通路／林下、濕地與岩邊；沒有平均灑滿碎物或逐棟房屋生成接地圈。

- `ground.res`：預先生成遮罩，含粗糙度／細法線與局部接地。幾何不位移。
- `decor.scn`：209件、58個MultiMesh批次，落葉／細枝／石粒／木屑；尊重來源與通路留白，无碰撞、不投影。
- `wear.scn`：三處原生磨耗Decal，避免額外常駐512²替代烘焙圖。
- `outline.gdshader`：保留現行時段與光照效果，先查身份記號再做地面高度辨識。
- `outline_data.res`：地面辨識所用遮罩與高度格點，僅適用現行168m ranch。

變更ranch擺設、尺寸或地形時應重新產製；此批預烘焙資源不會自行重新解釋新地圖的生活痕跡。
