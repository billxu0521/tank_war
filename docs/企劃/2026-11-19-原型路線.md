# 原型路線：0.8.16 → 團隊模式

日期：2026-11-19。把 [0.8.16](2026-11-19-0.8.16-一般模式與規則改動.md) 和 [團隊模式](2026-11-19-團隊模式.md) 排成一步一步。這份只排順序，機制的細節在那兩份。

## 結論

- **0.8.16 先，團隊模式後**。0.8.16 有三樣東西團隊模式要用：固定一個人當恐龍、按住幾秒的互動、畫面上的標記。
- 0.8.16 拆 9 步，分三條線，三個人可以同時做。
- 團隊模式的**第 0 步（量 10 個人的負擔）不用等**，現在就能跟 0.8.16 一起做，它只加工具不改遊戲。
- 團隊模式做到 T4 就是**最小可玩版**（1 個真人＋9 個電腦可以打完一場）。之後 5 個延後的機制互相獨立，可以同時做。
- 每一步：一個合併請求、做完能玩、測試跟著加、電腦跟著會。跑測試看最後一行「OK：…」（解析錯誤也會回 0）。

**可以同時做的**

- T0 跟整個 0.8.16 同時。
- T2（牛仔身上：`cowboy.gd`、`team.gd`）和 T3（密碼：`safe.gd`、`party.gd`、`safe_panel.gd`）同時。
- T5、T6、T7、T9 同時。它們都會在 `team.gd` 加東西，各加各的函式。T8 的自救可以同時做，復活那半等 T6。

**最小可玩版有什麼、沒有什麼**

| 有（T1～T3） | 沒有（延後） |
| :--- | :--- |
| 三隊、隊友不互傷、隊色標記 | 選隊畫面 |
| 倒地、爬、隊友救 | 持蛋者復活、小蛋自救（出局就是出局） |
| 三位數、兩種信封、隊內共享 | 拷問、吞掉的信封 |
| 所有信封都標在方位條上 | 「只標最近一封／兩封」的標記規則 |
| 帶蛋撤離的隊贏、時間到尼諾拉贏 | 特殊恐龍 |
| 電腦會：不打隊友、救人、用隊伍情報、護送 | 電腦會：復活、拷問、搶小蛋 |

為什麼這樣切：這四樣少任何一樣都不算「團隊」模式；延後的五樣少了還是玩得完一場。延後的裡面最先該加的是 T6（持蛋者復活），因為 12 分鐘只有一條命，早出局的人要看很久。
