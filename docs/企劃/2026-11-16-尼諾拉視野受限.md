# 尼諾拉視野受限

日期：2026-11-16。來源：使用者回饋「尼諾拉的視角需要再放大，希望視野受限，現在情報能力太強；要讓獵人容易逃離牠的視線」。只是規劃，還沒做。講的是**真人駕駛**的尼諾拉；電腦的見第 5 節。

## 1. 現在真人尼諾拉拿得到什麼

| 來源 | 知道什麼 | 在哪 |
| :--- | :--- | :--- |
| 鏡頭 | 鏡頭在身後約 15 公尺、離地約 14 公尺（比建築、柵欄、灌木都高），垂直視角 55 度（寬螢幕左右約 85 度）。滑鼠可以瞬間轉一圈，身體才慢慢跟上 | `boss.gd` 鏡頭、`balance.csv` 的 `dino_cam_*` |
| 看多遠 | 幾乎沒上限。霧很淡（100 公尺外才蓋掉兩成） | `main.tscn` `fog_density` 0.002 |
| 牛仔的輪廓光 | 牛仔是「目標」：身上加亮邊和粗線，30 公尺外還換成更顯眼的橘紅色，線到 300 公尺才淡完。蹲著、在草叢裡都一樣亮 | `outline.gdshader` 的 `rim_far_*`、`target_fade_end` |
| 方位條：蛋 | 有人拿著蛋，方位條**即時**標出他的方向和距離 | `match_hud.gd` `compass_marks` |
| 方位條：信封 | 信封被開的那一刻變灰、寫「（已開）」：知道剛剛有人在那 | 同上 |
| 方位條：保險箱、撤離、星星、金色小恐龍 | 位置和距離（星星在人身上也標） | 同上 |
| 方位條：小恐龍叫 | 小恐龍的位置標 5 秒（同一隻 20 秒叫一次，看得到站著 12、蹲著 6 公尺） | `raptors.gd`、`raptor_mark_seconds` |
| 計分欄 | 誰拿著蛋（名字，沒有位置） | `party_hud.gd` |
| 聲音 | 槍聲、爆炸整張圖聽得到；腳步 35 公尺、牛仔喊聲 45 公尺。有方向 | `weapon.gd`、`cowboy.gd` |

牛仔現在能躲的：建築和牆擋視線、拉遠、等牠體力見底（跑約 10 秒）、繞著牠跑（身體每秒轉 3 弧度）。
**草叢和蹲下只對電腦有用**（電腦看站著 18、蹲著 9 公尺、正面左右各 60 度、蹲在草叢裡看不到）；真人從 14 公尺高往下看，加上輪廓光，躲不掉。

最強的三樣：輪廓光＋看無限遠、蛋的即時標記、高處俯視。

## 2. 「視角放大」怎麼做

| 做法 | 效果 | 副作用 |
| :--- | :--- | :--- |
| 鏡頭拉近 | 身體佔畫面更多、擋住中間；鏡頭也跟著矮一點 | 太近看不到腳邊和頭前面；背後有牆時鏡頭會進到身體裡（`CAM_PULL_MIN` 要從 0.35 調到 0.5） |
| 視角變窄 | 左右看到的少，要多轉頭 | 低於 45 度像望遠鏡，轉頭容易暈 |
| 遠處起霧 | 遠的人直接看不到，最直接 | 要連輪廓光一起關，不然牛仔會在霧裡發亮；只有尼諾拉那台起霧，牛仔畫面不變 |
| 畫面周圍變暗 | 兩側看不清楚 | 悶、醜，寬螢幕沒差多少。不建議 |

咬的圈圈是從頭前面那一點投影到畫面上的，鏡頭怎麼改它都會跟著對（所見即所得不受影響），只要把圈圈半徑上限 `RING_MAX` 從 90 放寬到 120 像素。

**建議組合**（都放 `balance.csv`，好調）：

| 項目 | 現在 | 建議 |
| :--- | :--- | :--- |
| `dino_cam_dist` 鏡頭在身後多遠 | 10 | 7 |
| `dino_cam_fov` 垂直視角 | 55 | 48（左右約 77 度） |
| `dino_cam_height` 鏡頭高度 | 4 | 4（不動：再低身體會擋住咬的範圍） |
| 新 `dino_fog_begin`／`dino_fog_end` 駕駛那台的霧 | 無 | 25 公尺開始、70 公尺全蓋掉 |
| 新 `dino_rim_end` 牛仔輪廓光看多遠 | 300 | 20 公尺開始淡、40 公尺沒有 |

40 公尺外的牛仔變成霧裡一個小黑影，70 公尺外看不到。電腦尼諾拉看 18 公尺，真人還是比電腦看得遠。
遠山不吃霧（本來就是），所以方向感還在。時段（`period.gd`）會換霧，駕駛的霧要蓋在它上面。

## 3. 削情報

| 項目 | 建議 |
| :--- | :--- |
| 蛋的即時標記 | **改**：對尼諾拉每 5 秒更新一次、只給方向不寫距離。蛋掉在地上照舊。牛仔看到的不變 |
| 牛仔輪廓光 | **改**：見第 2 節；另外蹲著的牛仔對尼諾拉沒有輪廓光 |
| 信封「（已開）」 | 先不動：只有一次，等於一聲響。上面兩項做完還太強再延遲 10 秒 |
| 小恐龍叫 | 不動：這是尼諾拉自己花力氣放的耳目，其他情報削掉之後它才有價值 |
| 保險箱、撤離、星星 | 不動：牠本來就該知道要守哪 |
| 計分欄、聲音 | 不動：聲音是公平的管道，牛仔可以選擇不開槍、不跑 |

## 4. 讓牛仔容易逃

| 項目 | 建議 |
| :--- | :--- |
| 蹲在草叢裡看不到 | **做**：在尼諾拉駕駛那台，蹲在草叢裡的牛仔不畫出來，5 公尺內才現形；開槍現形 1 秒。跟電腦同一條規則（`hidden_in_bush`、`FEEL`） |
| 遠了看不到 | **做**：就是第 2 節的霧，拉開 40 公尺以上就脫身 |
| 不能瞬間回頭 | 先不做：鏡頭只能看身體左右各 90 度，回頭要等身體轉。滑鼠會有拖著的感覺，前面幾項試玩後還太強再加 |
| 轉身變慢 | 不做：`dino_turn` 3.0 再慢，咬人會很難瞄 |
| 跑步畫面晃 | 不做：會暈 |
| 追丟沒提示 | 現在就沒有提示，不用改 |

## 5. 電腦尼諾拉

不用跟著改。電腦不看畫面，本來就照「18 公尺、蹲 9 公尺、草叢看不到、正面 120 度」的規則，比改完的真人還弱。這次改的全在駕駛那台的畫面和方位條，bot_sim 的撤離率（55～72%）不會動。

唯一要對齊的：守箱的電腦在開箱後是直接走向蛋的準確位置。如果真人改成 5 秒更新一次，電腦也改成用 5 秒前的位置，兩邊才一樣；改完要重跑 bot_sim 40 回合。

## 6. 怎麼做、怎麼驗

1. 鏡頭三個數字＋`CAM_PULL_MIN`＋`RING_MAX`（`balance.csv`、`boss.gd`、`match_hud.gd`）。小。
2. 駕駛那台的霧和輪廓光距離（`boss.gd` 切換駕駛時設、`outline.gdshader` 加一個距離參數、`period.gd`）。中。
3. 蛋的標記 5 秒更新（`match_hud.gd`；電腦對齊在 `boss.gd`）。小。
4. 草叢藏人（`cowboy.gd` 在駕駛那台藏模型）。小。

驗收：沙盒當尼諾拉，牛仔站在 20、40、70 公尺各截一張圖，改前改後並排放 `docs/image/`；背後貼牆時鏡頭不進身體；咬的圈圈變紅時真的咬得到；牛仔那台畫面沒變。
