## 目前玩法整理（2026-10-17）

大框架、牛仔操作、恐龍的行為原則定了；**勝負條件還沒定**。現在遊戲裡的搶蛋是坦克版留下來先沿用的。

### 已經定的

1. **大框架：Hunt 那一類**
   - 多個玩家當第一人稱牛仔，互相競爭。
   - 場上一隻電腦控制的大恐龍（尼諾拉）到處找人，是所有人共同的威脅，不屬於任何一方。
   - wdr77 的總結（09-10）：「就是 Hunt Showdown，只是把賞金跟 boss 分離，boss 可以逛大街。」
   - 09-25 的設計是主機玩家當恐龍（`docs/規劃/2026-09-25-cowboy-vs-dino-design.md`），後來改成電腦操控。
2. **牛仔怎麼打（照 Hunt）**
   - 子彈有限、沒有準心、舉槍會晃（Shift 閉氣停住）。
   - 左輪、單管散彈、槓桿步槍、炸彈長矛，加炸藥；有效射程內打頭一槍死。炸藥和長矛不分敵我。
   - 翻越、蹲、槍托；跳不過柵欄，要翻。
   - 對槍 L0 做完了，可以測。
3. **恐龍的原則**（細節見 `恐龍行為.md`）
   - 眼睛差、耳朵好：開槍（幾乎全圖都聽得到）、在牠附近跑步，會把牠引來。
   - 一陣一陣來：追久了會自己退開、放鬆，再回來。
   - 三招出招前都有預兆，看懂就躲得掉；蓄力甩尾時打頭可以打斷。
   - 打不死（搶蛋模式）：打死恐龍如果算贏，理性玩法會變成大家先聯手殺恐龍，跟互相競爭矛盾。
   - 恐龍不能撿蛋，只當威脅。
4. **死亡的代價是節奏**：5 秒重生、次數不限，損失時間和身上掉在原地的東西。

### 還沒定的

1. **勝負條件**：現在是搶蛋（帶蛋進撤離區，一局 4 分鐘）。下面的派對版、戰術版都還沒拍板。
2. **尼諾拉在遊戲裡的定位**：wdr77（10-17）認為玩法要先宏觀再微觀，這題要最先決定。
3. **尼諾拉追不追得到人**：wdr77（10-17）問要不要像 Hunt 的怪，玩家一直跑就不會死。要的話，讓牠攻擊後發呆，可以只在打中後發呆，或每次攻擊後都發呆；要殺死人，就靠其他怪物或獵人干涉，或玩家貪刀。billxu 認為現在已經不太會追到死，反而有點笨。
4. **為什麼要冒險**（世界觀、委託組織、為什麼值錢）：gio_cpy 的提案在寫（10-14 WBP_v1.0），暫時不卡玩法。

wdr77（10-17）也提醒：玩法還空白時先做故事和美術，會缺少判斷「適不適合」的核心方向。billxu 提議下一階段先測對槍，再把玩法放進去。

### 09-10 的模擬和討論（補記）

## 待決策：勝負條件要不要從「打死對方」換成「偷蛋」

現在的版本是純殲滅（恐龍血歸零 / 坦克全滅）。討論裡提出換成偷蛋，有兩個版本。

### A. 派對版（wdr77 明確傾向這個）

- 一顆蛋，**放在鴕鳥背上**，鴕鳥會在地圖上跑
- 防守方不能賴在蛋旁邊，得跟著鴕鳥移動
- 鴕鳥平時在中央簡單走動；玩家太靠近、或砲彈飛過，就會亂跑一段時間
- 攻擊方要先用砲把鴕鳥打暈，再趁機摸蛋
- 鴕鳥比所有人快，但會停在幾個定點讓玩家跟上
- 坦克拿到蛋直接掛在車後（參考馬車的氣球模式）
- 三階段：**打鴕鳥 → 搶蛋 → 撤離**
- 陣型 1v1v1v1：三台坦克 + 一隻恐龍

選它的理由（wdr77）：門檻低、規則視覺化、簡單又新鮮、**體驗到樂趣的時間點早**。
上限不一定高，但適合先做。

### B. 戰術版

- 2~3 顆蛋，每顆放在籠子／柵欄圍起來的封鎖區
- 偷蛋前要先開閘門，閘門是攻防戰術核心
- 開閘門要找開關，一個門可能有兩個開關
- 待定：按下開關後固定時間必開，還是像 Hunt 的氣閥門可以被中途關掉
- 防守方可以放陷阱、插眼守蛋
- 參考：DBD + Hunt

未解問題（wdr77 自己提出的）：多顆蛋怎麼算勝負？三個守住兩個算贏，還是不設明確勝負、只影響獎勵？

### C. 兩階段版（billxu 提出後自己收回）

P1 恐龍找地方擺蛋 / 坦克開偵測器摸地圖 → P2 恐龍防守、坦克搶。
gio_cpy 質疑「從一場遊戲要多久回推，兩階段會不會過擠」，billxu 回「單純一點好了」。
**已收回，不列入選項。**

## 待決策：兩邊的體質定位

這題底下有兩種主張，而且方向相反。

**gio_cpy（試玩 0.3 之後）**：血量應該互換。恐龍高速就該低血、坦克要皮厚。
他的具體理由是單人模式玩起來的感受——坦克追不到恐龍，又追不到、又要打一百下才打得死，
優勢不知道在哪。另外建議坦克**轉向變慢、但純直線可以比恐龍快**。

**billxu**：想要「巨 vs 巨」，差異放在機械 vs 生物。

**gio_cpy 的反駁**：巨 vs 巨想不到適合的玩法和博弈策略，會變成偏打架的爽感（像巨擊大亂鬥）。

**wdr77 的框架（這句話應該先於前面兩者）**：

> 設計起點不是數值，而是要從戰場定位著手。像 R6 攻擊方 vs 防禦方、
> DBD 生存者 vs 鬼，是對於勝利條件去做特化。實際上雙方體質可能不會差多，
> 只是一些關鍵能力不同。

也就是說：**勝負條件沒定之前，數值調不出對的答案**。上面那兩個主張都建立在
「純打架」的前提上；一旦換成偷蛋，「誰追得到誰」的意義會整個變。

## 建議的下一步

先回答 wdr77 那個問題：**勝負條件是什麼**。定了之後數值才有意義。

如果要做派對版，最小可玩的一版大概是：

1. 場上放一顆會跑的蛋（鴕鳥可以先用一個會移動的方塊代替）
2. 坦克撞到／靠近就撿起來，掛在車後
3. 帶到指定撤離點就贏；恐龍咬死持有者就把蛋掉回地上
4. 鴕鳥被砲彈打到會亂跑一段時間

這四點不動現有的移動、射擊、爬牆、視線判定，是加在上面的一層。
