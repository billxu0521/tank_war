# 選單流程：房間大廳、單人整理

日期：2026-11-20。只設計選單和進場流程，不改玩法。對照的程式是 0.8.16（`main.gd`、`match_rules.gd`、`party.gd`、`main.tscn`）。

## 結論

- **連線多一層「房間」**：開房或加入之後先進房間等人，不直接進場。房間裡看得到誰來了、現在選什麼模式。**房主**選模式和設定、按開始。一場打完**回房間**，不斷線，換模式不用重連。
- **房主是誰**：自己開房的就是開房的人（他走了房間就關，跟現在一樣）。專用伺服器是**最早連進來、還在線上的人**，他走了交給下一個最早的。
- **模式只推兩個**：一般（預設）、派對。團隊模式的位置先留著（灰的，T1 做完打開）。舊的四個（搶蛋、死鬥、對抗、恐龍決鬥）收進「其他模式」。
- **單人從 6 顆收成 3 顆**：跟電腦打（用同一個房間畫面，只是不連線）、練習場、其他（開發用的四個）。
- **做法是加，不是重寫**：規則表、想當恐龍的抽籤、中途接手電腦、斷線重連、存位址都沿用。新寫的只有房間的狀態和畫面。拆 6 步，前 2 步做完就有房間可以用。
- 0.8.16 已經全做完（A1～A9）。這份排在團隊模式 T1 **前面**：T1 要 10 個人先到齊、要分隊，沒有房間就沒地方做。

## 現在的選單有什麼

**首頁**：連線對戰、單人練習、設定、離開遊戲。

**連線對戰頁**

| 東西 | 做什麼 | 新流程怎麼處理 |
| :--- | :--- | :--- |
| 模式下拉：搶蛋、死鬥、對抗、恐龍決鬥、派對、一般 | 開房的人選，預設是第一個（搶蛋） | 搬進房間。一般、派對是重點；其他四個收進「其他模式」 |
| 1 局／4 局 | 選一般時才出現 | 搬進房間 |
| 我想當恐龍 | 連線**前**勾，連上之後改不了 | 搬進房間，隨時能改 |
| 開房 | 按了直接進場 | 留著，改成進房間 |
| 加入＋位址列（存、選存過的） | 按了直接進場 | 留著，改成進房間 |
| 連到測試站 | 現在沒有主機，按鈕是灰的 | 沒有主機時整顆藏起來 |

**單人練習頁**

| 東西 | 做什麼 | 新流程怎麼處理 |
| :--- | :--- | :--- |
| 單人派對 | 自己加 3 個電腦打派對四回合 | 換成「跟電腦打」（一般、派對都能選） |
| 沙盒 | 牧場上打靶、練翻越、油燈 | 改名「練習場」，留在第一層 |
| 靶場 | 另一張平地圖，跳傷害數字 | 收進「其他」 |
| 單人打恐龍 | 測恐龍行為，接關無限 | 收進「其他」 |
| 恐龍沙盒 | 自己當尼諾拉，按 H 叫獵人 | 收進「其他」 |
| 檢視模型 | 看模型 | 收進「其他」 |

**遊戲中**：Esc 選單（繼續、回大廳、離開遊戲，主機多一塊「遊戲局控制」）。結算畫面（主機有「重開一局」，大家有「回到大廳」）。

**現在的問題**

1. 按開房就進場，沒有等人的地方。一般模式是靠「準備階段結束那一刻才抽恐龍」繞過去的。
2. 加入的人進場前不知道是什麼模式。
3. 「我想當恐龍」只在連上那一刻送一次，連上之後勾了主機不知道。
4. 回大廳等於斷線。換模式要所有人重連。
5. 預設模式是搶蛋（最舊的）。最近做的一般模式排在下拉的最後一個。
6. 專用伺服器的模式寫在啟動參數裡，要換得重新部署；一局結束自動開下一局，沒人能停。
7. 單人頁有 6 顆按鈕，一半是開發用的；最近的一般模式沒有單人入口。

## 整體流程

```
首頁
├─ 連線 ──→ 連線頁 ──開房／加入──→ 房間 ──房主按開始──→ 遊戲 ──→ 結算 ──→ 房間
│                                    ↑                              │
│                                    └──────────────────────────────┘
├─ 單人 ──→ 單人頁 ─┬─ 跟電腦打 ──→ 房間（不連線，只有自己）──→ 遊戲 ──→ 結算 ──→ 房間
│                   ├─ 練習場 ──→ 直接進場
│                   └─ 其他 ──→ 靶場／單人打恐龍／恐龍沙盒／檢視模型
├─ 設定
└─ 離開遊戲
```

每一頁按 Esc 或「返回」回上一頁。在房間按「離開房間」才會斷線。

## 1. 連線

### 連線頁

```
┌──────────── 連線 ────────────┐
│ [ 開房 ]                      │
│                               │
│ 位址 [ 192.168.1.5    ] [＋][⋯]│
│ [ 加入 ]                      │
│                               │
│ [ ← 返回 ]                    │
└───────────────────────────────┘
```

- 這一頁不選模式。模式進了房間才選。
- 「連到測試站」只在 `TEST_SERVER` 有填的時候出現（現在沒有主機，所以看不到）。
- 位址列、存位址、選存過的位址照舊。

### 房間

```
┌──────────────────────── 房間 ────────────────────────┐
│ 模式  (●) 一般   ( ) 派對   ( ) 團隊（製作中）  [其他模式 ▾] │
│ 局數  (●) 4 局  ( ) 1 局                               │
│ 恐龍  (●) 抽想當的人  ( ) 電腦  ( ) 指定：玩家 2         │
│ 說明  整場固定一個人當恐龍……                            │
├───────────────────────────────────────────────────────┤
│ ★ 玩家 1（房主）        準備好了                         │
│   玩家 2   想當恐龍     準備好了                         │
│   玩家 3                還沒                             │
│   電腦會補到 3 個獵人                                    │
├───────────────────────────────────────────────────────┤
│ [x] 我想當恐龍      [ 準備 ]                             │
│ 本機位址 192.168.1.5（給朋友填）                         │
│ [ 開始 ]（只有房主）      [ 設定 ]  [ 離開房間 ]          │
└───────────────────────────────────────────────────────┘
```

**房主才能動的**：模式、局數、誰當恐龍、開始。其他人看得到這幾項，是灰的，房主一改每個人的畫面跟著變。

**每個人都能做的**

- 按「準備」（再按一次取消）。準備只是一盞燈，給房主看，不擋開始。
- 勾「我想當恐龍」。隨時能改，改了馬上送給主機。
- 開設定（鍵位、畫面、聲音）。
- 離開房間。

**選裝不搬進房間**：留在每局的準備階段（15 秒，現在的 `buy_menu.gd`）。理由：已經會動；每局都能換槍，放房間只能選一次。

**時段**（日落、正午、半夜）：照房主「設定」裡選的，跟現在一樣，不搬。

**模式列**

| 模式 | 狀態 | 設定 |
| :--- | :--- | :--- |
| 一般 | 重點，預設 | 1 局／4 局；誰當恐龍 |
| 派對 | 重點 | 沒有（輪流當恐龍、固定 4 回合） |
| 團隊 | 還沒做，灰的 | T1 做完打開；之後選隊也放這裡 |
| 其他模式：搶蛋、死鬥、對抗、恐龍決鬥 | 舊的，收進下拉 | 沒有。對抗的「抽想當的人」照舊用同一個勾 |

**誰當恐龍**（一般模式，之後團隊模式用同一套）

- 抽想當的人（預設）：按開始那一刻從勾的人裡抽一個。沒人勾就電腦當，真人全當獵人。
- 電腦：不管誰勾，都是電腦當。
- 指定：房主點名單上的一個人。
- 現在「準備階段結束那一刻才抽」的做法留著當補救：開場是電腦當、後來有人勾了，4 局的話下一局換他（0.8.16 第 1 節的規則，不改）。

### 誰是房主

| 情況 | 房主 | 他走了 |
| :--- | :--- | :--- |
| 有人用自己的電腦開房 | 開房的人 | 房間關掉，其他人回首頁，看到「主機斷線了」（現在就是這樣） |
| 專用伺服器 | 最早連進來、還在線上的人 | 交給下一個最早連進來的，名單上的 ★ 跟著換，所有人看到「玩家 2 現在是房主」 |

- 專用伺服器的房主斷線再連回來：不還給他，排到最後。簡單，不會兩個人搶。（要拍板第 3 題）
- 專用伺服器上**沒有任何人**：回到房間、設定回到啟動參數給的預設（`--mode`，沒給就是一般 4 局）、不開局、不跑電腦。第一個連進來的人就是房主。
- 專用伺服器打到一半所有人都走了：等 30 秒沒人回來就結束這場、回房間。現在派對模式會讓 4 個電腦一直打下去，白吃主機。
- 專用伺服器的啟動參數（`--mode`、`--period`）改成「房間的預設值」，不再是寫死的。
- 房主掛機不按開始：第一版不處理（朋友之間在 Discord 喊一聲）。之後要的話加「房主 60 秒沒動作、又有人準備好了，就換下一個」。

### 晚加入的人

| 連進來的時候 | 看到什麼 |
| :--- | :--- |
| 大家在房間 | 直接進房間，名單多一個人 |
| 一般模式打到一半 | 接手一個還活著的電腦獵人，畫面上一行字「一般模式 第 2／4 局，你接手電腦 2」。沒有活著的電腦就觀戰到下一局（現在的 `party.take_bot`） |
| 派對模式打到一半 | 觀戰到下一回合，下一回合頂掉一個電腦（現在的 `_refresh_roster`） |
| 團隊模式打到一半（之後） | 接手一個還站著的電腦隊員，沒有就觀戰（團隊模式文件第 1 節） |
| 其他模式打到一半 | 直接生一個牛仔（照舊） |

打完跟大家一起回房間。

### 一場打完

```
┌──────────── 結算 ────────────┐
│ 玩家 2 帶蛋撤離，獲勝          │
│ （4 局的話是計分表）           │
│                               │
│ 15 秒後回房間                 │
│ [ 同設定再來一場 ]（只有房主） │
│ [ 回房間 ]（只有房主，馬上回） │
│ [ 離開房間 ]                  │
└───────────────────────────────┘
```

- 預設**回房間**，不自動開下一場。大家的連線都留著，房主可以換模式或直接再開。
- 房主不想等就按「同設定再來一場」，跟現在的「重開一局」一樣快。
- 回房間的時候每個人的「準備」清掉，「想當恐龍」留著。
- 局和局之間（4 局的第 1 到第 2 局）不回房間，照現在的 8 秒結算直接下一局。

### 遊戲中的 Esc 選單

```
[ 繼續 ]
[ 結束這場，回房間 ]（只有房主，會再問一次）
[ 離開房間 ]（房主是開房的人時，字改成「關掉房間」，會再問一次）
[ 設定 ]
[ 離開遊戲 ]
── 遊戲局控制 ──（主機才有，照舊，開發用）
```

## 2. 單人

```
┌──────────── 單人 ────────────┐
│ [ 跟電腦打 ]  最近的模式，電腦補滿 │
│ [ 練習場 ]    打靶、練翻越、油燈   │
│ [ 其他 ▸ ]                        │
│ [ ← 返回 ]                        │
└───────────────────────────────────┘

┌──────────── 其他（開發用）────────────┐
│ [ 靶場 ]        平地，跳傷害和距離       │
│ [ 單人打恐龍 ]  測恐龍行為，接關無限     │
│ [ 恐龍沙盒 ]    當尼諾拉，H 叫獵人       │
│ [ 檢視模型 ]                             │
│ [ ← 返回 ]                               │
└──────────────────────────────────────────┘
```

**跟電腦打**：進同一個房間畫面，只是不連線、名單上只有自己、自己就是房主。選一般（1 局或 4 局、勾「我想當恐龍」就是自己當，不勾就當獵人）或派對，按開始。之後團隊模式做好，這裡自動就有「1 個真人加 9 個電腦」。

- 理由：不用另外做一套單人的模式選擇；連線有的模式單人一定有；一個人也能先看過房間畫面長怎樣。
- 取代現在的「單人派對」。

**練習場**：就是現在的沙盒，換個玩家看得懂的名字。新玩家第一次開遊戲要練槍、練翻越，放第一層。

**其他**：四個都是做遊戲的人在用的。不拿掉（測恐龍、測手感、看模型都還在用），但不該跟「跟電腦打」排在一起讓玩家選。啟動參數（`--sandbox`、`--range`、`--solo-dino`、`--dino-sandbox`、`--viewer`）全部照舊。

**為什麼不把舊模式拿掉**：它們只是規則表裡的幾筆資料，測試和啟動參數都還在用，留著不花力氣。收進下拉裡，玩家不會誤選就夠了。真的要刪是另一件事。（要拍板第 2 題）

## 3. 跟現在的程式差多少

**沿用，不用改**

| 現有的 | 在哪 | 用在 |
| :--- | :--- | :--- |
| 規則表 | `match_rules.gd` | 模式列直接讀；團隊模式加一筆就出現 |
| 換頁的做法 | `main.gd` 的 `LOBBY_PAGES`、`lobby_go` | 新的頁照登記 |
| 想當恐龍的名單、抽籤 | `_volunteers`、`dino_pool`、`party._pick_fixed` | 房間的勾選、誰當恐龍 |
| 主機告訴別人模式和時段 | `_set_rules`、`_set_period` | 房主改設定時每個人都收一次 |
| 中途接手電腦、下一局排進名單 | `party.take_bot`、`_refresh_roster` | 晚加入 |
| 斷線 60 秒內接回來 | `_reclaim`、`rekey`、玩家代號 | 照舊 |
| 存位址、版本檢查 | `_load_saved_ips`、`_on_auth` | 照舊 |
| 選裝 | `buy_menu.gd` | 照舊，留在準備階段 |
| 離線的連線物件 | `OfflineMultiplayerPeer`（單人派對在用） | 跟電腦打 |

**要新寫**

| 新的 | 說明 |
| :--- | :--- |
| 房間的狀態（新檔 `room.gd`） | 主機記：照連進來順序的名單、房主是誰、每個人準備了沒、現在的設定。有變就整包送給所有人（一次很小，不是每幀送） |
| 房間畫面 | 名單、模式列、設定、準備、開始 |
| 「連上但還沒開局」這個狀態 | 現在開房、連進來都馬上生牛仔（`_on_host_pressed`、`_spawn`）。要改成在房間時不生，房主按開始才生 |
| 打完回房間 | 現在只有「斷線回首頁」（`_to_lobby`）。要多一條「清掉場上的人和這場的狀態、連線留著」的路 |
| 房主不一定是編號 1 | 現在「主機＝房主」寫在很多地方（重開一局只有主機能按）。專用伺服器要改成認房主的編號 |

**要注意的**

- `tests/ui.gd`、`tests/match.gd` 有檢查首頁按鈕和「每顆按鈕都要登記在 `LOBBY_PAGES`」，改頁面要跟著改。
- 連線的改動要跑 `tools/net_check.sh`（本機開主機加兩個客戶端）。現在沒有測試主機，專用伺服器那一步只能這樣驗。
- 0.8.16 文件說「不在開房那一刻抽恐龍，因為那時還沒人連進來」；團隊模式文件說「準備階段拉長到 30 秒，讓人來得及連進來、勾選」。有了房間，這兩個理由都不在了：按開始就抽，團隊模式的準備階段不用為了等人拉長。那兩份文件不回頭改，以這份為準。

## 4. 實作步驟

每步一個合併請求，做完能玩。

| 步 | 做什麼 | 大小 | 等誰 | 做完玩家看到什麼 |
| :--- | :--- | :--- | :--- | :--- |
| M1 | 選單整理（只動介面）：預設模式改一般、舊四個排到後面標「舊」；單人頁收成「單人派對、練習場、其他」；測試站按鈕沒主機就藏 | 小 | — | 單人頁 3 顆；開房預設是一般 |
| M2 | 房間（自己開房）：開房、加入先進房間；名單；房主選模式和局數、按開始；「想當恐龍」搬進來隨時能改 | 中（最大的一步） | M1 | 可以等人到齊再開；加入的人進場前看得到模式 |
| M3 | 打完回房間：結算 15 秒後回房間、連線留著；「同設定再來一場」；Esc 選單的「結束這場，回房間」 | 中 | M2 | 換模式不用重連 |
| M4 | 單人「跟電腦打」走房間畫面，拿掉「單人派對」按鈕 | 小 | M2 | 一個人能打一般模式（當獵人或當恐龍） |
| M5 | 準備的燈、誰當恐龍三選一（抽、電腦、指定）、晚加入的那一行字 | 小 | M2 | 房主看得到誰好了、能指定恐龍 |
| M6 | 專用伺服器的房主：最早進來的人當、走了換人、沒人就回房間不開局、不再自動開下一局 | 中 | M3 | 專用伺服器上也能選模式（只能用 `tools/net_check.sh` 在本機驗） |

- M2 → M3 是主線。M4、M5 在 M2 之後可以同時做。
- M6 可以等到決定要不要開新主機再做（團隊模式第 7 題：量完再決定用自己的電腦開房還是開主機）。自己開房的話前 5 步就夠。
- M2 沒做 M3 之前，打完照現在的樣子（主機按「重開一局」、派對 30 秒後自動再開一場），不會壞。

**跟 0.8.16、團隊模式的關係**

## 5. 要拍板的

沒回答就照預設。預設都選「之後要改也好改」的那邊。

1. **一場打完回房間，還是自動開下一場？**
   預設：回房間（結算停 15 秒）。房主可以按「同設定再來一場」直接開。要改成自動下一場只是把那 15 秒之後做的事換掉。
2. **舊的四個模式（搶蛋、死鬥、對抗、恐龍決鬥）收起來還是拿掉？**
   預設：收進「其他模式」。拿掉要動測試和啟動參數，之後確定沒人玩再刪。
3. **專用伺服器的房主斷線，馬上換人還是等他 60 秒？**
   預設：馬上換給下一個最早進來的，他連回來排最後。等 60 秒的話這段時間沒人能按開始。
4. **在房間等人的時候，只看名單，還是可以在場地上走動熱身？**
   預設：只看名單。走動熱身要多做「熱身中的人怎麼收掉、熱身時能不能開槍」，房間能用之後再加不衝突。
5. **房主按開始要不要等所有人都準備好？**
   預設：不用等，房主隨時能開，準備只是一盞燈。要改成「全部準備好才能開」是加一個條件。
