# 電腦牛仔像真人：打分數選動作

日期：2026-11-13。來源：billxu 的需求「電腦牛仔要像真人，目標是把蛋帶出去（看牌 → 開箱 → 撿蛋 → 撤離）」。
狀態：製作順序做到第 4 步，第 5 步（照試玩調數字）等試玩（見最後「做到哪」）。數字都是起始值，要靠模擬和試玩調。

## 結論

- **不用決策樹，改成「打分數」**：每 0.4 秒把 8 個動作各算一個分數，做最高分的那個。要調行為就調分數，不用重排樹。
- **像真人靠四件事**，都是加在同一套分數上，不是另一套系統：
  1. **只知道看得到、聽得到的**：恐龍在視野外就不知道牠在哪，只記得最後看到的位置，8 秒後忘掉。
  2. **手腳慢一點**：看到恐龍 0.3～0.5 秒後才反應，轉身有速度上限，瞄準會偏，試密碼一次要 2.5～4 秒。
  3. **個性**：勇敢、膽小、投機三種，只是同一張分數表乘上不同的倍數。
  4. **不反覆**：選了一個動作至少做 2.5 秒，別的動作要高出 15 分才換。
- **分工是分數自己長出來的**：「已經有隊友要去這張牌」扣 30 分，第二個人自然去另一張。箱子有人在試，別人的「試密碼」扣 35 分，自然變成在旁邊守。
- **不用替牛仔烘導航網格**。打分數只決定「去哪」，不管「怎麼走」。要繞路的話，直接借尼諾拉那張網格（牠走得過的地方牛仔一定走得過），不花烘焙成本。先量卡牆的秒數，夠嚴重才接。
- **最小可玩的一版**：5 個動作（看牌、試密碼、撿蛋、撤離、躲）＋不反覆＋分工＋試密碼放慢＋頭上顯示分數。估一到兩天。這一版還是「全知」，感知下一步再加。
- **先量再改**：第 0 步先做模擬工具，量現在的電腦牛仔。沒有改之前的數字，就不知道有沒有變好。

## 現在有什麼

| 東西 | 在哪 | 現況 |
|---|---|---|---|---|---|---|
| 電腦牛仔的主迴圈 | `cowboy.gd` 的 `_bot_step` | 每個物理幀：看牌試密碼 → 算目標 → 走過去（卡牆沿牆繞 1.5 秒）→ 開槍 |
| 去哪 | `_bot_goal`、`_bot_card` | 固定優先序：箱沒開去牌或箱子；拿著蛋去最近的撤離點；蛋沒人拿去撿；別人拿著就追他 |
| 站著不動 | `_bot_should_hold` | 在箱子旁、撿蛋中、撤離中 |
| 看牌、試密碼 | `_bot_safe_act` | 經過信封 3 公尺內馬上看；在箱子旁每秒試一個 |
| 瞄誰 | `_bot_threat`、`_bush_hides` | 全場最近的敵人（恐龍或別的牛仔），不管有沒有牆擋。只有蹲草叢 6 公尺外看不到 |
| 開槍 | `_bot_shoot` | 每幀瞬間轉向對準，40 公尺內一直扣扳機 |
| 尼諾拉的感官 | `boss.gd` 的 `can_see`、`_heard`、`_look` | 視野錐、蹲著要更近、草叢、射線檢查牆、聽到的位置會偏、盯一下才確定。**這套直接抄** |
| 尼諾拉的走法 | `boss.gd` 的 `_nav_go`、`_go` | 照導航網格走，卡住一秒就退開重算 |
| 尼諾拉的節奏 | `director.gd` | 壓力值控制追和退。牛仔不需要 |
| 開發資訊 | `main.gd` 的 F3（`debug_hud`）、`match_hud.gd` 的 `_boss_debug` | 右上角已經有一行恐龍在幹嘛 |

**為什麼現在不像人**（看程式和先前的觀察）：

1. 永遠知道恐龍在哪，隔著房子也瞄著牠。
2. 瞬間轉身、瞬間開槍、不會偏。
3. 不怕死：恐龍在箱子旁邊也照樣走過去站著。
4. 三個人做一樣的事：都去最近的牌、都擠在箱子旁邊。
5. 開箱太快：第二張牌比箱子近就順路看；三個人接力試，一秒一個不間斷。
6. 別人拿到蛋就追著他打（派對模式裡他是隊友）。

## 動作表和分數

每個電腦牛仔每 0.4 秒算一次（三個人錯開，不擠在同一幀）。只在主機算。

### 共用的量

| 名字 | 算法 | 白話 |
|---|---|---|
| 近(d, R) | `clamp(1 − d/R, 0, 1)` | 距離 0 是 1，到 R 公尺變 0 |
| 險(位置) | `信心 × 近(那個位置到「記得的恐龍位置」, 35)` | 那個地方離恐龍多近。恐龍倒地時是 0；完全不知道恐龍在哪時固定 0.1 |
| 信心 | 看到時 1，之後 8 秒線性降到 0；只聽到是 0.6 起跳 | 對「恐龍在那裡」有多確定（見感知一節） |
| 急 | `clamp(1 − 剩餘秒數/90, 0, 1)` | 最後一分半開始急 |
| 傷 | `1 − 血量比例` | |
| 剩一命 | 只剩 1 條命是 1，否則 0 | |
| 有人搶 | 有隊友正要去同一個目標，而且比我近，是 1 | 電腦隊友直接讀他的動作；真人隊友用「比我近 10 公尺以上，而且正朝那邊走」猜 |

### 八個動作（起始數字）

分數大約落在 0～100。每次算完再加一個 ±5 的隨機數（選定動作後這個隨機數不變，到下次換動作才重抽），三個人才不會一模一樣。

| 動作 | 什麼時候能選 | 分數 | 做什麼 |
|---|---|---|---|
| **看牌**（兩張各算一次） | 箱沒開，這張我沒看過 | `60 − min(0.3×距離, 35) − 30×有人搶 − 40×險(牌)`；我已經看過一張再 `− 25` | 走到牌前 3 公尺，**站 0.8～1.5 秒**才看到數字 |
| **試密碼** | 箱沒開，我至少看過一張（或剩不到 60 秒，沒看也硬試） | `55 + 15×兩張都看過 + 25×急 − min(0.2×距離, 30) − 45×險(箱) − 35×(有人在試或有人搶)` | 走到箱子旁站著試。節奏見下面「試密碼放慢」 |
| **守箱** | 箱沒開，有隊友在試或正要去試 | `35 − min(0.1×距離, 15) − 30×險(自己)` | 站在箱子 8～12 公尺外，面向恐龍最後出現的方向，牠來了就打 |
| **撿蛋** | 箱開了，蛋沒人拿 | `75 + 25×急 − min(0.2×距離, 30) − 35×險(蛋) − 20×有人搶` | 走過去站滿 3 秒 |
| **撤離** | 我拿著蛋 | 固定 `95` | 去撤離點站滿 8 秒。挑哪個：`距離 + 60×險(撤離點)` 最小的那個（不一定最近，會避開恐龍） |
| **護送** | 隊友拿著蛋 | `55 − min(0.15×距離, 25)` | 走在拿蛋的人和恐龍之間，離他 6～10 公尺，恐龍來了就打 |
| **躲** | 隨時（拿著蛋時不能選，拿蛋的人只管跑） | `10 + 80×險(自己)×(0.4 + 0.6×傷) + 15×剩一命` | 往遠離恐龍的方向，找最近的草叢或牆後蹲著；有急救包就用 |
| **還擊** | 看得到恐龍，在射程內 | `10 + 25×血量比例 + 25×(3 秒內被打) + 25×(恐龍離正在試密碼或拿蛋的隊友不到 20 公尺) − 20×剩一命` | 停下來或橫著走，專心打 |

**幾個例子**（確認數字的方向對）：

- 滿血，30 公尺外看到恐龍：險 0.14。躲 14、還擊 35、去 50 公尺外的牌 45 → 繼續去看牌，邊走邊開槍（開槍是反射動作，不佔動作，見下）。
- 半血，恐龍 10 公尺、剛被打：險 0.71。躲 50、還擊 48 → 一般人差不多五五波；膽小的躲（75），勇敢的打（67）。
- 恐龍倒地 15 秒：險全部歸 0 → 看牌、試密碼、撿蛋的分數一起跳高，大家衝目標。這是真人會做的事，不用另外寫規則。
- 三個人開局：甲離十位數牌最近，去了。乙也離十位數近但比甲遠，被扣 30 → 改去個位數。丙兩張都被搶 → 離得近就還是去看一張，離得遠就去守箱。

**開槍不是動作，是反射**：腳照動作走，槍口另外管（現在就是這樣分的）。看得到恐龍、在射程內、不在看牌或試密碼，就開槍。「還擊」這個動作是指「腳也停下來專心打」。
另一個代理正在改的「在箱子旁不開槍，除非剛被打」照樣留著，跟這裡一致。

### 試密碼放慢

現在開太快有兩個原因：順路看第二張牌、三個人接力一秒一個。改法：

- 第二張牌扣 25 分：通常直接去試（看過一張最多 10 次），除非另一張真的很近。
- 到箱子旁先等 **1.0～2.0 秒**（真人要按 F、看面板）。
- 每次試完等 **1.5～3.0 秒**才試下一個（真人要選數字、按鈕）。加上試本身的 1 秒，一次大約 2.5～4 秒。
- 一次只有一個人在試：別人的「試密碼」被扣 35，會變成守箱或去看另一張牌。
- 估算：看過一張，平均試 5.5 次，約 18 秒，最慢約 35 秒。現在是 5～10 秒。真人要多久，等試玩的數字（見「怎麼量」）。

## 感知和記憶

**原則：電腦牛仔只能用真人畫面上有的資訊。**

| 資訊 | 真人怎麼知道 | 電腦怎麼知道 |
|---|---|---|
| 信封、撤離點的位置 | 方位條一直標 | 直接讀 |
| 保險箱的位置 | 看過牌方位條才標；或是親眼看到 | 看過牌才知道。沒看過又想跟（投機型）：跟著最近的隊友 |
| 蛋在哪、誰拿著 | 方位條 | 直接讀 |
| 試過哪些組合、箱子有沒有人在試 | 面板、箱子的提示字 | 直接讀 |
| 隊友的位置 | 看得到名字 | 直接讀（先不算視線，省事） |
| **恐龍在哪** | **只有看到、聽到** | **下面的規則** |

### 看

抄 `boss.can_see` 的寫法，數字換成人的：

- 視野：正前方左右各 55 度。
- 距離：恐龍 70 公尺內（牠 12 公尺高，很遠就看得到），別的牛仔 40 公尺內。
- 沒被擋住：從眼睛往恐龍的頭打一條射線，中間有牆或房子就看不到。每次算分數才打，不是每幀。
- 草叢：照現在的 `_bush_hides`。
- 貼身 6 公尺內不管方向都知道（腳步震動）。
- **頭要會轉**：走路時看前進方向；每 3～5 秒往旁邊或後面瞄 0.5 秒。不然視野錐等於永遠看前面，背後來的恐龍永遠不知道，又太笨。

### 聽

- 恐龍吼叫、出招：60 公尺內聽得到。
- 恐龍跑步：25 公尺內。
- 聽到的位置會偏，越遠偏越多（抄 `boss._heard`）。信心從 0.6 開始。
- 被打到：馬上知道攻擊來的方向（`fighter` 受傷時已經有來源位置）。

### 記

每個電腦牛仔只記三個東西：`恐龍位置`、`信心`、`上次看到的時刻`。

- 看到：位置更新，信心 = 1。
- 沒看到：信心每秒降 1/8，8 秒後歸 0，等於「不知道恐龍在哪」。
- 不知道的時候「險」固定 0.1：有一點怕，但不會不敢動。
- 死掉重生：信心歸 0。

所有「險」都用記得的位置算，不是恐龍真正的位置。所以恐龍繞到背後，電腦牛仔會像真人一樣被偷襲。

### 反應和瞄準

| 項目 | 現在 | 改成 |
|---|---|---|
| 發現恐龍到有反應 | 0 秒 | 0.3～0.5 秒（照個性），越遠越久。這段時間照原本的動作走 |
| 轉身 | 瞬間 | 每秒最多轉 360 度 |
| 瞄準 | 正中 | 偏 1.5 度；在走路再加 3 度；剛轉過來再加 2 度。偏的方向每 0.4 秒換一次、慢慢滑過去，不是每幀亂跳 |
| 開槍間隔 | 能開就開 | 每發之間多等 0.15～0.4 秒 |

30 公尺外偏 2 度大約是 1 公尺。恐龍很大，身體大多還是打得中，打頭會少很多。

## 個性

同一張分數表，乘上不同倍數。三個電腦牛仔照編號各拿一種（-1 勇敢、-2 膽小、-3 投機），固定不抽，模擬的結果才能重現。

| | 勇敢 | 膽小 | 投機 |
|---|---|---|---|
| 一句話 | 帶頭衝、愛打 | 先保命、躲得快 | 等別人開箱，再去搶蛋 |
| 「險」的倍數（越大越怕） | 0.6 | 1.5 | 1.0 |
| 還擊 | ×1.4 | ×0.6 | ×0.8 |
| 躲 | ×0.6 | ×1.5 | ×1.0 |
| 試密碼 | ×1.1 | ×0.9 | ×0.6 |
| 守箱 | ×0.8 | ×1.0 | ×1.6 |
| 撿蛋 | ×1.0 | ×0.9 | ×1.4 |
| 護送 | ×1.2 | ×1.0 | ×0.8 |
| 反應時間 | 0.3 秒 | 0.5 秒 | 0.4 秒 |
| 瞄準偏差 | ×0.8 | ×1.2 | ×1.0 |

看牌、撤離不乘（每個人都要做）。只有一兩個電腦牛仔時，照順序拿前面的個性。

## 不反覆的規則

- 正在做的動作 **加 15 分**。別的要高過這 15 分才換。
- 換了動作 **2.5 秒內不再換**。
- 例外，馬上重算、不管那 2.5 秒：
  - 被打到。
  - 恐龍第一次出現在 15 公尺內。
  - 動作做不下去了：牌看完了、箱子開了、蛋被別人撿了、拿蛋的人死了、自己死了重生。
- 隨機的 ±5 在動作期間不變（上面講過），避免兩個分數接近時每 0.4 秒跳來跳去。

## 怎麼接進 cowboy.gd

新增一個檔 `cowboy/bot_brain.gd`，只放「記憶＋算分數」。走路、開槍、看牌這些身體的事留在 `cowboy.gd`。
分開的理由：算分數那塊可以單獨測（給一組狀況，檢查哪個動作最高分），不用開整場遊戲。

| 現在的函式 | 怎麼處理 |
|---|---|
| `_bot_step` | 留著當外殼。走路、卡牆繞路那段不動。開頭多兩步：每幀更新感知的計時；每 0.4 秒叫 `brain.think()` 選動作 |
| `_bot_goal` | **換掉**。改成「照現在的動作回目標位置」（看牌 → 那張牌；試密碼 → 箱子；守箱 → 箱子外圈的點；躲 → 掩蔽點…）。沙盒那段（去找玩家打）照舊 |
| `_bot_card` | **刪掉**。兩張牌各是一個候選動作，分數裡已經有距離和「有人搶」 |
| `_bot_should_hold` | 留著，改成看動作：試密碼中、撿蛋中、撤離中、躲好了，才站著 |
| `_bot_safe_act` | 留著。看牌只在「看牌」動作、站滿時間後才叫 `party.read`；試密碼只在「試密碼」動作，間隔照上面放慢 |
| `_bot_threat` | 改成只回「看得到的」。派對模式不瞄別的牛仔（見問題 1）；「別人拿著蛋就瞄他」只留給各自為隊的模式 |
| `_bot_shoot` | 加轉身速度上限、反應延遲、瞄準偏差、開槍間隔。另一個代理加的「箱子旁不開槍，除非剛被打」留著 |
| `_bush_hides` | 留著，被新的「看得到嗎」呼叫 |
| `bt.gd`（行為樹） | 牛仔不用。尼諾拉繼續用 |

數字先寫成 `bot_brain.gd` 開頭的常數。調穩了、企劃想自己改，再搬進 `balance.csv`。

從尼諾拉借的東西：`can_see` 的寫法（視野錐、蹲、草叢、射線）、`_heard` 的「聽到的位置會偏」、`_seen_left` 的記憶倒數、`_look` 的「盯一下才確定，越遠越久」、`_go` 的「卡住一秒就退開」。都是照抄十幾行，不抽共用程式（兩邊的數字和對象都不同）。

## 走路：要不要導航網格

- **打分數不需要**。它只決定去哪。
- 現在的走法：直線走，頂到牆就沿牆繞 1.5 秒。場地是大方塊時夠用。
- 會出問題的地方：「躲」要繞到房子後面、撤離點挑遠的那個要繞過小鎮。直線加沿牆繞可能卡很久。
- **最便宜的做法：借尼諾拉的網格**。
  - 那張網格是照牠的體型烘的（半徑 3.6 公尺）。牠走得過的地方，牛仔一定走得過。
  - 每個電腦牛仔每秒問一次路（`NavigationServer3D.map_get_path`，`boss._nav_go` 就是這樣寫），沿著路點走。
  - 烘焙成本是零，因為網格本來就有。
  - 缺點：窄巷、室內、門不在網格上，電腦牛仔會繞大路。目標在網格外（屋內的牌）時，走到網格上最近的點，最後一段照舊直線加沿牆繞。
- **不建議另外烘一張牛仔體型的**：每次拆房子都要多重烘一次，主線程 6～17 毫秒（小恐龍規劃量過）。
- **先量再決定**：模擬工具記「卡牆秒數」。佔比低就不接，省一步。
- 要先確認：真人開尼諾拉的那幾回合，網格是不是也有烘（看起來是生恐龍時就烘，還沒實際驗）。

## 除錯：看得到它在想什麼
