# 槍枝 L0 規劃（這階段的目標）

依據：[槍枝參數規格 v2.3](../企劃/討論紀錄/2026-09-30-槍枝參數規格.md) 的 L0（33 列）。目標是規格說的「能玩、能比、能調」。
L1、L2 不做，但不刪規格。

## 現況對照

現在三把槍（左輪、槓桿步槍、單管散彈）已經能玩。**最大的落差是：散布、後座力、舉槍時間是三把槍共用一組**
（寫在 `cowboy/viewmodel.gd`），每把槍只有一個後座力倍率。L0 要每把槍各自一組。

統計：33 列裡 **15 列已經有、12 列要改（改成每把各自、或補上缺的行為）、6 列要新做**。

## 步驟

1. **參數搬家（手感不變）**：散布、後座力、舉槍時間從共用搬到每把槍，名字對齊規格。三把都先填現在的數字，
   玩起來要跟現在一模一樣——這一步只換位置，不改手感。
2. **補行為**：扳擊錘／拉栓真的擋開火、逐發裝填三段時間、衰減終止距離和最低傷害值、第一發完全準的開關、
   射擊類型欄位、瞄準按住／切換。
3. **能調**：一張參數表讓企劃直接改（見待決定 1），改完重開遊戲就生效。
4. **能比**：武器介紹——名稱、圖示、每分鐘射速（含／不含裝填兩種）、裝填時間、初速、傷害衰減。
   用規格裡的算法算，不另外填。
5. **驗收**：規格第 09 節的清單寫成自動測試（連按不能突破間隔、拉栓沒完成不能開、散布 0 還有後座力、
   後座力 0 還有散布、各種裝填情況子彈數不會多也不會少、調慢初速命中變晚但傷害不變、衰減各段傷害對）。

每一步做完都能玩、測試都過，再進下一步。

## 已決定（2026-09-30，照建議）

1. 參數表：做一張表格檔（CSV，Excel 打得開），企劃不用開 Godot，改完重開遊戲生效（第 3 步）
2. 扳擊錘、拉栓：開完槍自動做
3. 提早按開火：先不記住（要再按一次），做成開關
4. 逐發裝填中按開火：先維持「停下裝填、馬上開槍」，做成開關（規格建議的「只停不開」可切過去）
5. 左輪搧擊錘：留著，不算 L0 驗收
6. 後座力回正比例：做成數字（`recoil_return_ratio`，現在 0.7）
7. 瞄準第一發完全準：做成開關
8. 單管散彈：一起套同一套參數

## 刻意不做

  屏息晃動**留著不拆**，只是不列入 L0 驗收。
- 硬直、弱點倍率：規格說留到怪物和角色系統。現在已有的爆頭判定不動。
- 數值平衡：規格的數字都只是示例。L0 先把「能調」做好，數值等試玩再定。
