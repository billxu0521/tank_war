# 對抗模式：玩家操作尼諾拉

2026-10-18｜使用者拍板。跟最早的坦克版類似：一個人當恐龍，其他人當牛仔；牛仔彼此是敵人，也跟尼諾拉敵對。

## 決定了什麼

| 問題 | 決定 |
|---|---|
| 誰當尼諾拉 | **大廳自選**：勾「我想當恐龍」。每局開始從勾的人裡隨機抽一個；沒人勾就由電腦當（等於一般搶蛋） |
| 勝負 | **搶蛋規則**：牛仔把蛋帶進撤離區就那個牛仔贏；4 分鐘到沒人撤離 → **尼諾拉贏**（一般搶蛋是「沒人贏」） |
| 牛仔 | 互為敵人，死了 5 秒重生、不限次數（同搶蛋） |
| 尼諾拉的招 | **電腦版的三招**：咬、蓄力甩尾、撲擊，都有預備動作和吼聲。不吐火球、不跳、不爬 |
| 尼諾拉沒血 | 跟電腦版一樣：900 血打光倒地 6 秒、站起來滿血、不出場 |
| 撿蛋 | 尼諾拉不能撿（同現在） |

## 做法：電腦版尼諾拉讓玩家接手

另一個做法是把三招搬進舊的玩家恐龍 `dino.gd`，但三招、預備、叫聲、同步要再寫一份，以後兩邊會分岔，不採用。

- 尼諾拉照舊是主機上的 `boss.gd`（權限在主機，扣血、出招都主機算，同步沿用）。
- 多一個「駕駛」編號 `pilot`（同步給大家）。有駕駛時，行為樹不跑，改照駕駛送來的輸入動；沒有就照舊是電腦。
- 駕駛的電腦每幀把輸入送給主機（不可靠、最新的蓋掉舊的）：移動方向、看的方向（水平角、俯仰）、跑、三招的按鍵。
- 主機照電腦版的限制動：走 4／跑 11（跑吃體力）、轉身限速（約 170 度／秒，「繞著牠跑有用」不變）、三招的觸發距離不限但冷卻、預備時間、收招照原本。撲擊方向＝起跳時面對的方向。
- 駕駛斷線 → `pilot` 清掉，電腦接手。
- 一局結束、下一局重抽。

## 操作（駕駛那台）

| 鍵 | 動作 |
|---|---|
| WASD | 移動（相對鏡頭） |
| 滑鼠 | 看；身體慢慢轉向看的方向 |
| Shift | 跑（吃體力，見底只能走） |
| 左鍵 | 咬 |
| 右鍵 | 撲擊 |
| Space | 蓄力甩尾 |

第三人稱鏡頭（沿用 `dino.gd` 的鏡頭支點做法），畫面上有體力條、三招冷卻、方位條標蛋和撤離區。

## 驗收

- test_battle：對抗模式有駕駛時行為樹不跑；駕駛輸入讓尼諾拉移動、轉身有限速、三招會進預備；駕駛斷線電腦接手；時間到尼諾拉贏；沒人勾就是電腦。
- net_check：專用伺服器＋兩個客戶端，一個勾恐龍，確認被抽到、能動、能咬到另一個。
- 實際兩台開起來玩一次。

## 沒做的

- 抽恐龍的權重（一直抽到同一人）：先純隨機，玩過再說。
- 尼諾拉的嗅聞、聽聲音提示：電腦版靠導演，玩家版先什麼都不給，靠自己找。
