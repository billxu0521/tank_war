# 場景編輯：在 Godot 編輯器裡調整場地

場地上所有東西（房子、柵欄、樹、石頭、灌木、木桶……）都在 **`levels/ranch.tscn`** 這個場景檔裡。
遊戲開始時照這個檔蓋出來，所有人（連線的每一台）讀的是同一個檔，不用另外同步。

## 地圖分區

十字路把場地切成四塊：西北農社區、東北城鎮（一條主街＋兩排店面）、西南麥田、東南森林。沙盒靶場（南北路的南段）和撤離點（東西兩端）不動。

## 怎麼改

1. 用 Godot 打開專案，雙擊 `levels/ranch.tscn`。3D 畫面會畫出地形和所有物件。
2. **移動、轉向**：點選物件拖曳（跟一般 Godot 場景一樣），只看水平位置和水平朝向。
   **高度不用管**：放開就自動貼著地面。要疊高（例如草捆疊第二層）改右邊屬性面板的 `lift`。
3. **大小**：樹、石頭、灌木用縮放工具；穀倉改 `size`（寬 × 牆高 × 長）、柵欄改 `amount`（長度）、筒倉改 `amount`（高度）。
4. **刪除**：選起來按 Delete。**複製**：Ctrl+D。
5. **新增**：從左下「檔案系統」面板的 `levels/物件庫/` 把東西拖進場景（拖到對應的群組底下比較好找）。
6. **地面整平**：`地形` 群組裡的「整平區」（藍色圓盤）決定哪裡是平地。建築搬到丘陵上，要把整平區一起搬過去；
   改完整平區按根節點 `Level` 屬性面板上的 **「重算地形」**。
7. 存檔（Ctrl+S），跑遊戲看結果。

## 存檔前按「檢查擺設」

選根節點 `Level`，屬性面板上的 **「檢查擺設」** 會檢查：

- 會擋人的東西有沒有重疊（木箱卡在柵欄裡、柵欄穿過房子……）
- 撤離區、沙盒靶場有沒有被擋到
- 有沒有擺到場外（場邊有看不見的牆）
- 型號有沒有打錯（打錯會變成看不見的東西）
- 建築有沒有高過恐龍爬得到的上限

有問題的物件頭上會出現**紅色方塊**，問題列在下方「輸出」面板。遊戲的自我檢查（`test_battle.gd`）也跑同一支，有問題會失敗。

## 要注意的

- **門的順序**：穀倉和農舍的門照「建築」群組裡的順序命名（連線時靠名字對上同一扇門）。
  大家讀同一個檔所以不會錯，但**改了建築順序之後，舊版本的遊戲連不上新版本**（本來就要同一版）。
- **撤離區、沙盒靶場的位置是固定的**（寫在 `main.gd`），不在場景檔裡。
- **重新自動擺會蓋掉手調的結果**：`tools/bake_level.gd` 只在第一次、或確定要從頭來的時候跑。舊版從 git 拿得回來。
- 物件庫少了什麼種類：在 `tools/make_kit_presets.gd` 加一行再跑一次。新的物件種類要程式配合
  （`main.gd` 的 `_build_level`、`levels/level_item.gd`、`levels/level_preview.gd`、`levels/level_check.gd`）。

## 給寫程式的人

- 擺設清單：`main.gd` 的 `_level`，每樣東西一筆 `{kind, pos, yaw, ……}`。`_load_level` 從場景檔讀、`_generate_level` 自動擺，
  `_build_level` 照清單蓋。出生點避開、灌木藏人、麥田上色這些範圍在 `_reserve` 算
- `tools/level_fingerprint.gd`：把蓋出來的場地寫成文字指紋。改「怎麼蓋」的程式前後各存一份比對，一樣才算沒改壞
