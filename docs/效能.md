# 效能

## 怎麼量

```
PERF=3 godot --path . --disable-vsync --resolution 1920x1080 --script tools/style_shots.gd
```

開沙盒，跟風格檢查同樣的 15 個角度（`tools/style_shots.gd`），每個停 `PERF` 秒（前 0.5 秒不算），關垂直同步、不限幀率。印兩行：

- 幀時間（平均、最慢 1%、最慢）、腳本、物理、繪製指令（draw call，叫顯示卡畫一樣東西一次）、三角形
- **畫面和影子分開**的繪製指令和三角形

開發機（Apple M5 Pro）每秒約 250 張，幀時間被雜訊蓋住，**看不出改動有沒有用**。所以比的是繪製指令和三角形——
這兩個在弱一點的電腦（隊友的 Windows 筆電、內顯）上才是負擔。GPU 時間在 Metal 上讀不到（一直是 0）。

清點場上每種模型的數量和三角形：`tools/census.gd`（見最後）。

做了：

1. **影子最花**：要把場景再畫好幾遍，繪製指令是畫面本身的兩倍多。
   - 太陽影子距離 100 → 70 公尺（`main.tscn` 的 Sun）
   - 小東西（最長邊不到 2 公尺：桶子、箱子、乾草塊、草叢）不投影子、90 公尺外不畫（`main.gd` 的 `_lighten_small`）
2. **建築、小物件拿掉倒角**：一塊木板加一段倒角，三角形 12 → 44，一棟房子 2 萬 → 8 萬，遠看看不出差別。
   `blender/house.py`、`town.py`、`kit.py`、`props.py` 的 `finish(bevel=0.0)`；槍和牛仔近看，保留
3. **建模檢查的面數算錯**：`blender/pipeline.py` 的 `tris()` 以前算套用修改器之前的網格，倒角加的面沒算到，
   房子印 2 萬、預算 2.5 萬照過，匯出其實 8 萬。改成算匯出後真正的三角形
4. 美術那輪關掉了油畫筆觸（Kuwahara，全畫面每個像素取 8 塊扇形 × 半徑 7 的鄰居），順便省掉最重的一道全畫面效果

試過、更糟、退回：

- **把一樣的擺設手動合成 MultiMesh**：畫面繪製指令 493 → 656。引擎（Forward+）本來就會把同一個網格的東西合成一次畫，
  手動合反而打斷它，又少了逐個略過畫面外的
- **撒滿全場的樹、草叢分塊**：影子三角形少兩成，畫面繪製指令卻 493 → 960
- **遠景的樹換成匯入時的簡化版**：畫面三角形反而變多。引擎本來就會自動換簡化版（LOD），自己做的網格沒有多層簡化

沒動：

- 物理每秒 120 次：是為了修移動殘影特地拉高的（`docs/驗證標準.md`），物理一幀不到 1 毫秒
- 開場第一眼會頓一下（最慢一幀 17～33 毫秒）：第一次畫到某種材質時在準備它，之後就不會
