# 文件索引

程式碼以外的東西都在 `docs/`。程式怎麼跑、檔案做什麼見根目錄的 [README](../README.md)。

**新加入的人先讀**：[分工與合併請求](流程/分工與合併請求.md)（怎麼開分支、送合併請求、誰改哪個檔）。

## 資料夾

| 資料夾 | 放什麼 |
|---|---|
| [企劃/](企劃/) | 玩法、角色、敵人的設計，以及 Discord 討論的整理 |
| [美術/](美術/) | 美術風格指南、Shader 規格、怎麼檢驗畫面 |
| [素材流水線/](素材流水線/) | 模型怎麼做、怎麼迭代、物件表（誰在做什麼）、場地擺設 |
| [技術筆記/](技術筆記/) | 效能、程序化動畫、參考影片的筆記 |
| [流程/](流程/) | 分工和合併請求、問題回報、驗證標準 |
| [規劃/](規劃/) | 每次改版前寫的規劃，檔名開頭是日期（寫完就不再改，是當時的決定） |
| [發布/](發布/) | 跟遊戲一起打包給玩家的說明、第三方素材授權 |
| `image/` | 參考圖、對照圖。每一輪的迭代截圖（`*_iter/`）太大不進 git，定案的放 `image/final/` |
| `movie/` | 參考影片（太大，不進 git） |

## 依工作找

**企劃**
- [設計討論](企劃/設計討論.md)：Discord `#夢想之地` 的整理
- [恐龍行為](企劃/恐龍行為.md)：boss 怎麼找人、出招、數字在哪改
- [尼諾拉](企劃/尼諾拉.md)：恐龍的設定和製作規格（原文在 `企劃/尼諾拉_NIBA原文/`）
- [Hunt 操作機制分析](企劃/Hunt操作機制分析.md)：移動、體力、槍的手感參考
- `企劃/討論紀錄/`：槍枝參數規格、各版回饋

**美術**
- 風格指南：`美術/Low_Poly_西部奇幻FPS_美術風格指南.docx`
- Shader 規格：`美術/Western_Faceted_FPS_Shader_美術改善規格.docx`
- [美術風格檢驗](美術/美術風格檢驗.md)：拍固定角度、量畫面、審查的流程

**素材流水線**
- [物件表](素材流水線/物件表.md)：每個物件的狀態，**開工前在「進行中」登記**
- [程式建模迭代](素材流水線/程式建模迭代.md)：用參考圖把模型逼近的做法和教訓
- [blender/README](../blender/README.md)：每支建模腳本做什麼、怎麼重建
- [場景編輯](素材流水線/場景編輯.md)：在 Godot 編輯器裡擺場地
- [檢視模式](素材流水線/檢視模式.md)：新模型丟進 `models/` 就能在遊戲燈光下看（按 5 素材庫）

**程式**
- [效能](技術筆記/效能.md)：怎麼量、量過什麼、試過哪些沒用
- [程序化動畫](技術筆記/程序化動畫.md)
- [問題回報](流程/問題回報.md)：玩家按 F8 貼上來的報告怎麼讀

**發版**
- 版號只動第三碼（0.8.x），改 `project.godot`、`export_presets.cfg`、[發布/說明.txt](發布/說明.txt) 三處，`./build.sh` 打包
