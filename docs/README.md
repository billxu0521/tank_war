# 文件索引

程式碼以外的東西都在 `docs/`。程式怎麼跑、檔案做什麼見根目錄的 [README](../README.md)。

這個資料夾的 `.md` 會自動鏡像到 Obsidian（`OvD 法外狂徒大戰恐龍/文件/`，唯讀，跟 GitHub 上的 main）。
文件只在這裡改，Obsidian 那邊改了會被蓋掉。同步用 `tools/sync_obsidian.sh`（新電腦先跑一次 `--install` 裝 git hook，之後提交、拉取、切分支都會自動同步）。

**筆記原則**
- 「不讀好幾個檔案或 git 歷史就看不出來」的事（踩坑、隱藏規則、做過的決策），做完補進對應的文件；新文件在下面的索引補一行。
- 一條一行，寫「規則 + 原因」，不寫過程。
- 過時或錯了就直接改或刪，不要堆疊。`規劃/` 例外：那是當時的決定，寫完不改。
- 程式碼、git 歷史已經看得出來的事不要記。

**新加入的人先讀**：[分工與合併請求](流程/分工與合併請求.md)（怎麼開分支、送合併請求、誰改哪個檔）。
