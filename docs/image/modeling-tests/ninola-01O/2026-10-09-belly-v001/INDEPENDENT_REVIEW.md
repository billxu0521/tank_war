# 獨立造型審視：通過有限收腹粗模方向

v003可作依黃線自然收腹的有限候選，交使用者比較；非動態或Production驗收。

1. 側面右圖腹線x1110–1240、y570–615：吊腹明显收起，前高后渐降，符合黃線意圖。灰模也可见；頸肩保持N1，不沿用被否決O1。
2. 左右3/4腹側／正面下顎後下方：比直接切掉吊塊更連貫，未見新增針狀突出。正面有偏平橫折面、側面後端留角點，可接受作Low-poly粗模，不稱圓順或解剖完成；暗面与前肢遮擋非破洞證據。
3. 全身側与後3/4：改動集中腹側，胸腔背部側身的厚實重量仍在，未變細腰或削空軀幹。先停此幅度供使用者確認，後續承接再看身體姿態中的腹皮／肢體根轉接。
