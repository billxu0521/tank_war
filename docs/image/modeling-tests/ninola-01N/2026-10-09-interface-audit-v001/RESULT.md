# 01N.1 固定口緣—外壁診斷 — 2026-10-09

使用者已接受01N.1 v003，以非像素化呈現為準，同时同意仍有釐清空間，授權直接執行接口診斷。当前工作checkpoint升為01N1 v003，M8保留回退。獨立造型意見保留；本次更正部分可見突起的身份，不把使用者接受等同Production驗收。

## 發現一：先前「接口尖瓣」判讀需要分開

對本次sweep003原圖做像素射線核對，(502,449)、(552,406)、(599,355)多數射線命中原有d_bone、jaw權重的下顎牙齒；前端(390,537)也命中牙齒，但僅一條射線有命中，支持較弱。(531,470)、(567,423)命中原有d_mouth、jaw的口腔面。這六處都在保留面中，不是新外皮。

因此不能繼續把這些抽查突起視為新外壁長出的裂片，或以消掉它們為修模目標。前輪把部分突起統稱尖瓣不夠準確，現已逐面更正；歷史審查不重寫成從未發生。此辨識僅限抽查位置，不證明所有尖折都正常，也不證明完整咬合通過。

## 發現二：固定交界不是平順的外輪廓

27個固定幾何位置皆存在於新外皮的頂邊，沒有缺失；來源相鄰保護面材料都是d_mouth，因此這是外顎與原口腔的交界，不是外皮自由設計線，也不是Rig軸。边界三維高度範圍1.63534～1.88448來源單位，部分側向也有內凹。這些是模型測量，不是Concept尺寸。

v003第一層collar幾乎逐點向下.020，直接繼承原交界的起伏。這解釋為何外皮接合容易讀到起伏與折線；不能據此宣稱有破洞，亦不能推論必須移牙或骨架。

新外皮自身27條開放邊正好是這一圈接口，197面內沒有邊被超過兩面共用。座標對接完整不等於整模型索引已焊接或Production manifold通過；原來源有平面著色重複點。

## 發現三：新外皮面繞序確實有問題

197個新外皮面內，21條共享邊的兩個相鄰面以同向走過該邊。這是具體的局部繞序不一致，與是否喜歡顎身造型無關。上一輪從單一中心估算外向法線的方式，不能可靠處理口緣與凹轉面。

診斷假設以相鄰面關係傳遞一致方向，再參照固定口腔邊的方向，僅反轉12個面即可將新外皮內這一項計數清為0。沒有移動頂點、改權重或改骨架。

原pose、既有咬擊026與大張口sweep003皆已渲染「原面序／僅修繞序」比較。兩者評估座標完全相同，因此可见牙齒輪廓與大形不会因此消失，證明繞序修正不能取代外形設計。這只是臨時顯示網格的假設測試，沒有產出修正版工作.blend，也沒有修正已核可來源。
