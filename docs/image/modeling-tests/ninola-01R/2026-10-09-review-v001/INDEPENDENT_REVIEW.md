# 01R 獨立審視

通過：限審視定位與R1示意提案，非全身造型／工程驗收。

1. 頭3/4灰模吻側x300–580 y440–560，下顎x280–555 y580–640：連續大面／規律細格與身體粗大不規則轉面不同，灰模存在，支持主面整理。
2. 上色頭顎：吻側單一橄欖、顎身连续金黃較平；Concept區域主次可供分組，避免隨機加色或三角噪聲。
3. 全身側／3/4／頂：已核可重量主次一致，沒有足夠理由推翻比例；Concept不同姿態不直接定縮放。
4. 背3/4：肩背大刺到尾端漸小成立；頭頂小刺較規律，本輪先留，不加刺掩蓋主面問題。
5. 頭正面眼睛x395／705 y420附近：小與偏側，威懾不能靠分色保證改善。RVI004保持。R1只比鼻背／吻側／後顱／顎身主面色面，固定輪廓／Rig／口腔牙列與核可量體。
