# 01Q.1 獨立示意審視

通過：限尾部方向討論，足以提出有限Prototype，不需擴大到骨盆／全尾。

1. 側面右圖x1090–1285、y430–505與控制圖腹線：少量補腰、收中段鼓包成立；綠腹線較規整，實作不可照抄成長直平底，應保留自然厚薄與角面。
2. 頂視右圖x1145–1255、y350–550：少量收寬保留粗根重量，沒有明顯削成細管；優先中段，不為每截面追完全單調。
3. 近根包絡端與全身：根尺寸／尾長尖保持；控制尺寸不變不證明原皮共點固定或接合完成。
4. 3/4背側棘刺：基部尚未貼合，先定位skin/spine共點與端界；受限時回報，不移刺／改Rig。原皮極值虛線非頂點位移指令。

建議維持有限幅度，先解算接口與範圍，由使用者決定是否實作。造型／weights／動態待實體驗證。
