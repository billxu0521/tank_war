# 01M.2 — 整體頭部識別與動態接口重塑提案

狀態：具體方案待審；尚未修改模型。依已同意的「先動態驗證 → 提出整體方案 → 核准後重塑並重測」流程。

## 目標與起點

以01M.1 v002作工作起點，保留其有效下顎收束，01L.3 v002保持最近通過／rollback。目標是接近Concept中可信、具壓迫感的頭顱與攻擊讀形；本輪取得整體blockout落地，不追求完美或一次完成Production Cleanup。

## 一起處理的外形範圍

1. 吻部：重新建立前端至眉部的高低與寬窄節奏，減少盒形平板；避免等比放大整頭。
2. 眉眼／眼眶：建立眉脊遮擋、凹入眼眶與眼裂，必要時獨立重建Low-poly眼球。golden-eye可取虹膜方向，裸露球體不直接沿用。
3. 後顱／顎支：加強後顱承載量體與顎後端層次，和頭頸入口銜接；保留下顎腹側收束，不再單獨削薄下巴。
4. 必要口緣接口：圈定已偵測3998／2653等局部軟表面接合區，可局部重建外口緣、內側連接面及其weights，以配合現有jaw軸；眼／頭皮新面同樣需局部蒙皮。明確記錄edit mask與變更面／頂點，避免只用材質遮住交疊。

不在本輪移動／重建牙齒齒列或舌，不以零jaw角度強求闭口。若固定牙齒或原jaw軸成為不可解限制，先記錄證據與影響，再提出另案；不自行改Rig。

## 硬限制與風險

Rig／Bones名称、階層、rest、原件pose及骨骼數保持；evaluation pose只在副本。足部、身體、尾及非頭部區域保持。01J／原Trex及其Shape Keys不改，不替換正式GLB。

大幅Mesh重塑可以採用局部重建拓樸；Prototype新面weights需檢查，新眼球跟隨既有head骨，不能增加骨。风险包括原jaw軸限制後顎形態、眉眼過深遮住眼睛、正面過寬、頭頸接縫或張口露洞。頭部量體通過不等於Shape Key相容或Production通過。

## 執行與驗收方式

先另存新版本，建立來源hash／隔離物件與精確範圍；完成一輪整體大形試作，再提供側／正／頂／三分之四、全身與Concept對照，包含面數與Rig檢查。

沿用本次固定相機、同一套咬擊／吼叫矩陣及jaw掃描，比較M1／M2。核查眉眼在抬頭與張口仍有可信視線、顎支量體完整、非修改區不變及沒有新增可見破洞；口緣問題逐對定位，未解者列RVI-004，不以單一無交叉畫面宣告合格。再作桌面MCP多視角與獨立審查。

交付時必須包含點評、剩餘問題與後續建議；使用者採納後才成為新工作落地點。保留失敗試作與技術記錄，不Commit／Push／PR。
