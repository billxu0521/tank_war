## 主要視覺問題與Concept方向

1. 下顎：M1減少腹側吊塊與後端直落，張口三分之四視角更乾淨；正面與下方口底仍寬平，不能把內部口底全當作外部下巴繼續削薄。
2. 吻部：目前前段偏盒形、輪廓高低與寬窄節奏不足。Concept的威嚇感來自吻部、眉脊與後顱共同形成的層次，不是單純放大整頭。
3. 眼眶：目前小凸點眼球缺乏眉部遮擋、眼裂與眼眶凹入。先建立承載眼睛的結構，再決定虹膜顏色與眼球尺寸，避免裸露大球造成滑稽感。
4. 後顱／顎支：後端硬折、頭頸承接平板；咬擊與抬頭吼叫更容易暴露。需從側面、正面、三分之四及全身共同判讀。

五張AI Concept是使用者確認的視覺目標，不是精確解剖／Rig測量圖；golden-eye僅可選歷史風格參考，不必直接採用。
