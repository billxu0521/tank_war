# B結構示意獨立審查

通過：限於結構示意可供使用者批准Blockout，非修改後模型／遮擋／咬合／Concept完成驗收。

1. 三分之四右圖鼻吻與頂視前端：中央鼻背、斜吻面及上顎側面分組清楚；寬厚短弧吻端符合綠／紅標註主面方向，未變尖喙。
2. 側視眼區與三分之四前眶：藍色前眶到上眉表達包覆，剖面上厚下輕合理。實作須接入頭皮主面，不生成獨立貼片或等厚C形套環。
3. 正視眼旁眉尾：線框不代表完成輪廓；眉尾須低而厚地融入眶上，避免向外尖角、人類眉毛或新增額刺。
4. 剖面球面／虹膜比例：不能照圖直接套尺寸；需同時看正面瞳孔可視面、側面眶深与眉遮，不能把變小／變暗自動判為壓迫感。
5. 頂視共同目標：意圖清楚，但真正視軸需模型坐標與多視圖確認，不能把示意金線視為遮擋驗證。
6. 側視上顎下緣及紫線：保護提示成立，仍需實作後同姿態咬擊／吼叫驗接口及牙齒不被新面遮擋。

審查者實際查看五張示意及使用者標註，未修改模型或檔案。
