## 玩法／數值

- 重生點要離恐龍和蛋 100 公尺以上（數字可議）（gio）
- 能持續跑的時間砍一半左右（gio）
- 往後跑要比較慢：面向和移動方向一致 100%，完全相反 75%，中間照角度遞減（gio）
- 跑步時的持槍動畫（billxu，要素想法串）
- 恐龍的行為模式：攻擊加前搖（出手前的預備動作，讓人看得出要打了）（billxu，要素想法串）

## 問題（billxu 已回答，2026-09-29）

1. 移動時鏡頭和人（含槍）不完全同步、有慣性，是故意的嗎？
   → 試試看不留慣性（已關掉槍的拖曳）
2. 蓄力近戰時還能開槍、舉槍、換彈，要留嗎？
   → 不留（已改）
3. 穀倉裡有扇人過不去的小門，是彩蛋嗎？（video3：穀倉後門）
   → 不是，是穀倉隨機縮放把門縮小了。做成正式門（已改：大穀倉站著過、小棚子蹲著過）
4. 跑步和近戰兩條體力要不要合成一條？
   → 要。而且體力不夠不再擋跳躍、翻越、近戰，只影響移動速度（已改）
5. 開 Esc 選單後還能做開槍以外的動作，要留嗎？
   → 先不動
