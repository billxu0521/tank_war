# 程序化動畫筆記

來源：[Procedural Animation is EASY](https://www.youtube.com/watch?v=7yXqfESL5qo)

不預先做關鍵影格，直接用程式算出生物的動作。核心是三招。

---

## 為什麼要這樣做

傳統做法要為多足生物準備「各個方向 × 各種速度」的動畫組合，再寫一堆狀態機轉場邏輯把它們接起來。
數量是相乘的，很快就爆炸。

程式化動畫在執行時依物理和環境即時算，不需要窮舉。

**但不是要取代關鍵影格。** 兩者混用最好：關鍵影格給你控制力（招式、演出），
程式化給你動態反應（慣性、地形、速度）。

---

## 第 1 招：旋轉延遲傳遞

**原理**：骨鏈的第一節跟著某個來源轉，之後每一節每幀先重設，再「部分追隨」前一節**上一幀**的角度。

- 追不上前一節 → **延遲**
- 追過頭 → **過衝**，也就是彈性

**用在哪**：尾巴、脖子、軀幹。頭一轉，尾巴就會甩出去再回彈。

**實作**（本專案 `trex.gd` 的 `_propagate()`）：每一節用一個彈簧–阻尼去追目標角度。

```gdscript
func _propagate(ang, vel, driver, stiff, damp, delta):
	var prev = ang.duplicate()          # 一定要用上一幀的值，不然會瞬間傳到底
	for i in ang.size():
		var target = driver if i == 0 else prev[i - 1]
		vel[i] += (target - ang[i]) * stiff * delta
		vel[i] *= exp(-damp * delta)    # 這樣寫才跟幀率無關
		ang[i] += vel[i] * delta
```

兩個旋鈕：
- `stiff` 越大追得越緊，延遲越短
- `damp` 越小晃越久，過衝越明顯

**驅動來源**要選對。本專案用「身體這一幀轉了多快」：

```gdscript
var yaw_rate = wrapf(yaw - _yaw_prev, -PI, PI) / delta
var driver = clampf(-yaw_rate * 0.20, -0.65, 0.65)   # 負號 = 往反方向甩，這就是慣性
```

實測本專案的暴龍（4 節尾巴）：

| 時機 | 尾巴根 | 尾巴尖 |
|---|---|---|
| 轉身當下 | −0.34 | −0.00 ← 完全跟不上，這就是延遲 |
| 停止轉身後 | ≈0 | +0.30 ← 反向甩過頭，這就是過衝 |
| 再過幾秒 | 0 | 0 ← 收斂 |

## 第 2 招：圓周運動 + IK 解算（本專案還沒做）

**原理**：腳的 IK 目標掛在一個旋轉的圓上，圓周走完一圈就是一個步伐。各隻腳的**相位錯開**。

**關鍵細節**：
- 圓周的旋轉速度跟角色移動速度掛鉤 → 走多快腳就動多快，不用做多套動畫
- 配**射線檢測**把目標壓到地面，就不會穿地，上下坡也自動貼合
- 離開地面時，把整個圓軌往**後上方**移動 → 動作自然變成划水，可以直接拿來當游泳

**跟本專案的差距**：現在的腳是直接用 `sin()` 轉大腿角度，沒有 IK，所以會穿地、上坡會浮空。

---

## 第 3 招：位置平移延遲（本專案還沒做）

**原理**：第 1 招是對「旋轉」做延遲，這招是對「位置」做同樣的事——
末端目標（前肢、頭）的位置也用彈簧去追它該在的地方。

**效果**：身體移動時肢體慢半拍地跟上，產生重量感。
